# `fused beta`

Discover the `fused.beta` methods published by the Fused team.

```
fused beta [SUBCOMMAND] [OPTIONS]
```

## Subcommands

| Subcommand | Description |
|---|---|
| `catalog` | List every published canvas and method, or show one (`canvas` or `canvas.udf`) in full. |
| `skill` | Write DIRECTORY/SKILL.md, an agent skill listing the `fused.beta` methods. |

## `fused beta catalog`

List every published canvas and method, or show one (`canvas` or `canvas.udf`) in full.

```
fused beta catalog [NAME]
```


## `fused beta skill`

Write DIRECTORY/SKILL.md, an agent skill listing the `fused.beta` methods.

```
fused beta skill DIRECTORY
```
