# `fused workbench claude`

Manage Fused for Claude Code (via the `claude` CLI).

```
fused workbench claude [SUBCOMMAND] [OPTIONS]
```

## Subcommands

| Subcommand | Description |
|---|---|
| `add-mcp` | Add a canvas MCP server to Claude Code. |
| `plugin` | Add, update, or remove the Fused workbench plugin for Claude Code. |

## `fused workbench claude add-mcp`

Add a canvas MCP server to Claude Code.

```
fused workbench claude add-mcp CANVAS_REF [OPTIONS]
```

**Options**

| Flag | Description |
|---|---|
| `--token` | Treat the provided reference as a shared canvas token (fc_...). |
| `--team` | Treat the provided reference as a team canvas name. |
| `--id` | Treat the provided reference as a canvas ID. |
| `--create-session-token / --no-create-session-token` | Create a session token for team-scoped canvases when none is passed. (default: `True`) |
| `--session-max-age TEXT` | Lifetime for --create-session-token (e.g. 30m, 1h, 1d). (default: `1h`) |


## `fused workbench claude plugin`

Add, update, or remove the Fused workbench plugin for Claude Code.

| Subcommand | Description |
|---|---|
| `add` | Register the marketplace and install workbench@fused-marketplace. |
| `remove` | Remove workbench@fused-marketplace. |
| `update` | Update workbench@fused-marketplace. |

### `fused workbench claude plugin add`

Register the marketplace and install workbench@fused-marketplace.

```
fused workbench claude plugin add
```

### `fused workbench claude plugin remove`

Remove workbench@fused-marketplace.

```
fused workbench claude plugin remove
```

### `fused workbench claude plugin update`

Update workbench@fused-marketplace.

```
fused workbench claude plugin update
```
