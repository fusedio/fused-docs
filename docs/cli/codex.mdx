# `fused codex`

Manage Fused for Codex (via the `codex` CLI).

```
fused codex [SUBCOMMAND] [OPTIONS]
```

## Subcommands

| Subcommand | Description |
|---|---|
| `plugin` | Add, update, or remove the Fused workbench plugin for Codex. |

## `fused codex plugin`

Add, update, or remove the Fused workbench plugin for Codex.

| Subcommand | Description |
|---|---|
| `add` | Register the marketplace and install workbench@fused-marketplace. |
| `remove` | Remove workbench@fused-marketplace. |
| `update` | Update workbench@fused-marketplace. |

### `fused codex plugin add`

Register the marketplace and install workbench@fused-marketplace.

```
fused codex plugin add
```

### `fused codex plugin remove`

Remove workbench@fused-marketplace.

```
fused codex plugin remove
```

### `fused codex plugin update`

Update workbench@fused-marketplace.

```
fused codex plugin update
```
