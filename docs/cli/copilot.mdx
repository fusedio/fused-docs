# `fused copilot`

Manage Fused for GitHub Copilot CLI (via the `copilot` CLI).

```
fused copilot [SUBCOMMAND] [OPTIONS]
```

## Subcommands

| Subcommand | Description |
|---|---|
| `plugin` | Add, update, or remove the Fused workbench plugin for GitHub Copilot CLI. |

## `fused copilot plugin`

Add, update, or remove the Fused workbench plugin for GitHub Copilot CLI.

| Subcommand | Description |
|---|---|
| `add` | Register the marketplace and install workbench@fused-marketplace. |
| `remove` | Remove workbench@fused-marketplace. |
| `update` | Update workbench@fused-marketplace. |

### `fused copilot plugin add`

Register the marketplace and install workbench@fused-marketplace.

```
fused copilot plugin add
```

### `fused copilot plugin remove`

Remove workbench@fused-marketplace.

```
fused copilot plugin remove
```

### `fused copilot plugin update`

Update workbench@fused-marketplace.

```
fused copilot plugin update
```
