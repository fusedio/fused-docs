# `fused workbench job`

List, inspect and cancel batch jobs.

```
fused workbench job [SUBCOMMAND] [OPTIONS]
```

## Subcommands

| Subcommand | Description |
|---|---|
| `cancel` | Cancel a running job. |
| `list` | List your jobs, most recent first. |
| `logs` | Print a job's logs. |
| `metrics` | Summarize CPU, memory and disk use of one or more jobs. |
| `status` | Show the status and task progress of a job. |

## `fused workbench job cancel`

Cancel a running job.

```
fused workbench job cancel JOB_ID [OPTIONS]
```

**Options**

| Flag | Description |
|---|---|
| `-y, --yes` | Cancel without asking for confirmation. |


## `fused workbench job list`

List your jobs, most recent first.

```
fused workbench job list [OPTIONS]
```

**Options**

| Flag | Description |
|---|---|
| `--name TEXT` | Only jobs whose name matches this pattern (case-insensitive, no wildcards). Repeat to match any of several. |
| `--match [contains\|startsWith\|endsWith\|equals\|notContains]` | How --name is compared. Defaults to contains. |
| `--status [Pending\|Starting\|In_Progress\|Done\|Failed\|Canceled]` | Only jobs with this status. Repeat to match any of several. |
| `--since TIME` | Only jobs submitted at or after this time: a date, an ISO 8601 time (UTC unless it has an offset), or a duration back from now such as 24h or 7d. |
| `--until TIME` | Only jobs submitted at or before this time, in the same forms as --since. A date alone includes the whole day. |
| `-n, --limit INTEGER RANGE` | Maximum number of jobs to list. (default: `25`) |
| `--all` | List every matching job instead of stopping at --limit. |
| `--sort [creation_date\|name\|job_status\|owner\|instance_type]` | Field to sort by. Defaults to creation_date. |
| `--asc` | Sort ascending instead of descending. |


## `fused workbench job logs`

Print a job's logs.

```
fused workbench job logs JOB_ID [OPTIONS]
```

**Options**

| Flag | Description |
|---|---|
| `-f, --follow` | Keep printing new log lines until the job finishes. |
| `--timeout FLOAT` | With --follow, stop after this many seconds. |


## `fused workbench job metrics`

Summarize CPU, memory and disk use of one or more jobs.

```
fused workbench job metrics [JOB_IDS...] [OPTIONS]
```

**Options**

| Flag | Description |
|---|---|
| `--series` | Output every sampled point instead of a summary (implies JSON). |


## `fused workbench job status`

Show the status and task progress of a job.

```
fused workbench job status JOB_ID
```
