# CLI Reference

The `fused` CLI lets you manage Fused from your terminal — run UDFs, manage canvases and files, handle secrets, and connect integrations. It ships with the `fused` Python package and needs Python 3.10 or newer.

## Install

Install it with [uv](https://docs.astral.sh/uv/getting-started/installation/), which puts `fused` on your PATH and picks a compatible Python for you:

```bash
uv tool install fused
```

Or install it with pip in a Python 3.10+ environment:

```bash
pip install --upgrade "fused>=2"
```

Every command runs as `fused workbench <command>`. Run `fused workbench --help` to check the install. To upgrade later, run `uv tool upgrade fused` or rerun the pip command.

:::warning
On Python 3.9, `pip install fused` installs fused 1.x, which has no `fused` command, so your shell reports `command not found: fused`. The `"fused>=2"` pin makes pip fail with an error instead. Run `python3 --version` to check: the `python3` that ships with macOS is 3.9.
:::

## Global flags

These flags apply to every command:

| Flag | Env var | Description |
|---|---|---|
| `--env TEXT` | `FUSED_ENV` | Override the Fused environment: dev, stg, prod, unstable, or a deployment URL. |
| `--format [json\|text]` | `FUSED_CLI_FORMAT` | Output format for command results (json or text). |

When `--env` targets the `base_url` that `~/.fused/settings.toml` sets explicitly, that file's `[auth]` is kept. Any other target uses the default Fused sign-in.

| Command | Description |
|---|---|
| [`fused workbench beta`](/cli/beta) | Discover the `fused.beta` methods published by the Fused team. |
| [`fused workbench canvas`](/cli/canvas) | Manage canvases. |
| [`fused workbench checkpoint`](/cli/checkpoint) | Manage canvas checkpoints. |
| [`fused workbench claude`](/cli/claude) | Manage Fused for Claude Code (via the `claude` CLI). |
| [`fused workbench codex`](/cli/codex) | Manage Fused for Codex (via the `codex` CLI). |
| [`fused workbench completion`](/cli/completion) | Print or install shell tab completion for the fused CLI. |
| [`fused workbench copilot`](/cli/copilot) | Manage Fused for GitHub Copilot CLI (via the `copilot` CLI). |
| [`fused workbench cronjob`](/cli/cronjob) | Manage scheduled UDF runs. |
| [`fused workbench files`](/cli/files) | Manage files stored in Fused. |
| [`fused workbench integrations`](/cli/integrations) | Manage third-party integrations in Fused. |
| [`fused workbench job`](/cli/job) | List, inspect and cancel batch jobs. |
| [`fused workbench json-ui`](/cli/json-ui) | Inspect and run JSON-UI widgets. |
| [`fused workbench login`](/cli/login) | Authenticate and persist credentials. |
| [`fused workbench logout`](/cli/logout) | Log out and clear local credentials. |
| [`fused workbench run`](/cli/run) | Run a UDF and print the result. |
| [`fused workbench secrets`](/cli/secrets) | Manage kernel and user secrets. |
| [`fused workbench udf`](/cli/udf) | Search and manage UDFs. |
| [`fused workbench udf-schema`](/cli/udf-schema) | Print the API schema for a UDF. |
| [`fused workbench whoami`](/cli/whoami) | Show info about the authenticated user or team. |
