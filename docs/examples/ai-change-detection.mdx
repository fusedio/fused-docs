If you've ever wanted to answer "did anything change here between last year and this year?" from satellite data, this canvas does exactly that — without writing a single line of image-processing code. Draw a box anywhere on Earth, pick a year, and three synchronized maps show you the landscape, its structure, and where things changed.

## What you can do with it

This canvas is useful whenever you need to quickly answer questions like:

- **Which fields were harvested or rotated?** — bright pixels in the change map show up where the crop cycle shifted.
- **Where did new development happen?** — roads, buildings, and cleared land all appear as high-change areas.
- **How stable is this landscape over time?** — dark areas in the change map have been untouched year after year.

The underlying dataset covers the whole globe from 2017 to 2024, so you can explore anywhere — not just a pre-selected region.

## How the canvas is organized

The canvas has one control node that feeds three analysis nodes. Change the AOI or the year in the control, and all three maps update automatically.

### 0 · Select area + year

Draw a bounding box on the satellite basemap and pick a year from the slider. This broadcasts two parameters — `bounds` and `year` — to every downstream node. Start with a small area (a few kilometers across) so the analysis runs in a few seconds.

### 1 · RGB (embedding bands 0-2)

The first three bands of the AEF embedding rendered as a false-color image. Think of this as a "what does this place look like to the AI" view — a baseline to orient yourself before you look at the change map.

### 2 · PCA of the full embedding

All 64 embedding dimensions are compressed to 3 using PCA, then mapped to RGB. The dominant variance in the landscape — field edges, crop types, bare soil — pops out in this view in ways that raw satellite bands often don't show clearly.

### 3 · Cosine-distance change map

This is the core of the canvas. For each pixel, it computes the cosine distance between the 64-dimensional embedding vector in year Y and year Y-1. The result is rendered with the magma colormap: **bright = large change, dark = stable**.

The key thing here is that it's comparing *embedding vectors*, not raw pixel brightness. That means it picks up semantic change — a field going from fallow to irrigated crops — not just lighting differences between two overpass times.

## About the data

The canvas reads from the [Agricultural Embedding Foundation (AEF)](https://source.coop/tge-labs/aef-mosaic/), a global Zarr dataset hosted on source.coop. Each pixel is a 64-dimensional vector produced by a vision model trained on multi-year satellite time series. The store covers 2017–2024 and only the two years you're comparing are read — so queries stay fast even though the full dataset is several terabytes.
