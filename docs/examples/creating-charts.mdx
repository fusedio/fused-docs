# Creating Charts

A chart in a Fused canvas draws the output of a UDF. There are two ways to make one:

- **A chart widget**: a JSON-UI component such as `line-chart` or `bar-chart` that runs SQL over a UDF's output. You write no chart code.
- **A UDF that returns HTML**: for any chart the widgets don't draw, build the page with a library such as Chart.js, Plotly or D3, and return it as a string.

## The data

`era5_daily` reads daily 2 m air temperature from Fused's public ERA5 dataset with [`fused.h3.query()`](/python-sdk/api-reference/h3#query). By default it returns farmland around Ames, Iowa, for June and July 2024: 21,960 rows, one per H3 cell (360 cells) and day (61 days).

```python
@fused.udf
def udf(
    min_lng: float = -93.9,
    min_lat: float = 41.8,
    max_lng: float = -93.4,
    max_lat: float = 42.2,
    date_min: str = "2024-06-01",
    date_max: str = "2024-07-31",
):
    """Daily ERA5 2 m temperature (°C) per H3 res-7 hex for a bbox and date range."""
    df = fused.h3.query(
        "s3://us-west-2.opendata.source.coop/fused/era5-hex/era5_daily",
        bbox=(min_lng, min_lat, max_lng, max_lat),
        time_min=date_min, time_max=date_max,
        columns=["hex", "date", "t2m_min", "t2m_max", "t2m_mean"],
    )
    for col in ["t2m_min", "t2m_max", "t2m_mean"]:
        df[col] = (df[col].astype("float64") - 273.15).round(2)  # Kelvin -> Celsius
    df["hex"] = df["hex"].astype("int64")
    return df.sort_values(["hex", "date"]).reset_index(drop=True)
```

## Simple: a line chart widget

The `line-chart` widget averages the 360 cells for each day and draws one line.

<iframe
  src="https://www.fused.io/share/fc_2v5D4mwPHr4AMvpmhTTVGt/daily_temperature"
  width="100%"
  height="450px"
  frameBorder="0"
  loading="lazy"
  style={{borderRadius: '8px'}}
></iframe>

```json
{
  "type": "line-chart",
  "props": {
    "title": "Average daily temperature (°C), Ames, Iowa",
    "sql": "SELECT strftime(date, '%Y-%m-%d') AS label, ROUND(AVG(t2m_mean), 1) AS value FROM {{era5_daily}} GROUP BY 1 ORDER BY 1",
    "beginAtZero": false,
    "showArea": false
  }
}
```

- `{{era5_daily}}` is the UDF's output. The SQL runs in DuckDB in the browser, so editing it does not run the UDF again.
- The chart reads two columns: `label` for the x-axis and `value` for the y-axis. Add a `series` column to draw one line per value.
- `date` is a date, so `strftime` formats it as `2024-06-01`. Without it the axis shows full timestamps such as `2024-06-01T00:00:00.000Z`.
- In the canvas, draw an edge from `era5_daily` to the widget.

## Complex: a custom chart from a UDF

`temperature_band` draws what the `line-chart` widget can't: the daily low to high range as a band, the mean as a line, and the days with an average high above a threshold as red points. Move the slider to change the threshold.

<iframe
  src="https://www.fused.io/share/fc_2v5D4mwPHr4AMvpmhTTVGt/temperature_dashboard"
  width="100%"
  height="650px"
  frameBorder="0"
  loading="lazy"
  style={{borderRadius: '8px'}}
></iframe>

How it works:

1. `temperature_band` calls `fused.run("era5_daily")` and averages the cells for each day with pandas. With the default threshold of 30 °C, 18 of the 61 days are hot.
2. It returns an HTML page that draws the chart with [Chart.js](https://www.chartjs.org/). A UDF that returns a string is shown as HTML.
3. The `temperature_dashboard` widget puts a `slider` above an `iframe` widget. The slider sets the canvas parameter `heat_threshold`, and the iframe runs `temperature_band` with it.

```json
{
  "type": "div",
  "props": {"style": "display: flex; flex-direction: column; gap: 8px; height: 100%; padding: 8px"},
  "children": [
    {
      "type": "slider",
      "props": {"label": "Hot day threshold (°C)", "param": "heat_threshold", "min": 25, "max": 35, "step": 0.5, "defaultValue": 30}
    },
    {
      "type": "iframe",
      "props": {
        "src": "{{temperature_band?heat_threshold=$heat_threshold}}",
        "title": "Daily temperature band",
        "style": "flex: 1; min-height: 460px; border: none"
      }
    }
  ]
}
```

The UDF is also an HTTP endpoint, so any page can show the chart with the threshold set in the URL. For example, [see the chart with a 32 °C threshold](https://udf.ai/fc_2v5D4mwPHr4AMvpmhTTVGt/temperature_band.html?heat_threshold=32).

## Chart widgets

Each chart widget runs a `sql` query over `{{udf_name}}` and reads the columns below by name. Every prop is on the widget's page.

| Widget | Draws | SQL columns |
|---|---|---|
| [`line-chart`](/widget-api/line-chart) | Lines over time | `label`, `value`, optional `series` |
| [`bar-chart`](/widget-api/bar-chart) | One bar per category | `label`, `value` |
| [`stacked-bar-chart`](/widget-api/stacked-bar-chart) | Bars split into stacked parts | `label`, `series`, `value` |
| [`stacked-area-chart`](/widget-api/stacked-area-chart) | Areas stacked over time | `label`, `series`, `value` |
| [`scatter-chart`](/widget-api/scatter-chart) | Points on two numeric axes | `x`, `y`, optional `series`, `size`, `label` |
| [`donut-chart`](/widget-api/donut-chart) | Shares of a whole | `label`, `value` |
| [`heatmap-chart`](/widget-api/heatmap-chart) | A grid of colored cells | `x`, `y`, `value` |
| [`metric`](/widget-api/metric) | One number, such as a total | The first column of the first row |

To place charts and inputs side by side, see [Widgets](/guide/data-input-outputs/import-connection/widgets).
