Satellite images are often cloudy. A composite combines several passes over the same place into one clear image. Draw a box on the map, pick a date range, and this canvas builds a 10 m Sentinel-2 composite you can download as a GeoTIFF.

<ClickZoomImage src="/img/examples/sentinel-2-composite.png" alt="Sentinel-2 composite canvas: the dashboard with band, date and quality controls next to a true-colour median composite over New York City and the scene table, above the data-processing nodes" />

## Try it out

[**Open the Canvas →**](https://www.fused.io/canvas/fc_fused/Sentinel2_Composite)

:::tip
The dashboard opens on a stored composite of New York. Draw your own box and click **Run composite** to make a new one.
:::

## 1 · Dashboard

- **Area**: click **Draw box** and drag on the map, or use the current view.
- **Bands**: any three Sentinel-2 bands, with presets for true colour, false colour and SWIR.
- **Dates** and **Settings**: the date range, how cloudy an image may be, and how to combine them (`median` by default).
- **Machines**: how many parts of the area run at the same time, up to 200.

When the run finishes, click **Download COG** to save the image.

## 2 · Find the images

`s2_scenes` lists the Sentinel-2 images that cover your box in the date range, least cloudy first:

```bash
curl "https://udf.ai/fc_fused/Sentinel2_Composite/s2_scenes/run/file?format=csv&aoi=-74.05,40.68,-73.90,40.82&date_start=2025-06-01&date_end=2025-09-30&max_cloud=10&limit=5"
```

## 3 · Build the composite

The box is split into square blocks of about 10 km. Each block runs on its own machine: `s2_composite` loads the clearest images for that block with [`odc.stac`](https://odc-stac.readthedocs.io/) and takes the median of each pixel over time. That keeps the ground and drops most clouds. Finished blocks are saved, so running the same settings again is instant.

## 4 · Download

The blocks are then joined into one Cloud-Optimized GeoTIFF (COG), cut to your box. The map shows it at every zoom level, and **Download COG** saves it.

## About the data

| Property | Value |
|---|---|
| Imagery | Sentinel-2 L2A, AWS Open Data |
| Scene catalog | [tge-labs `s2-stac-geoparquet`](https://source.coop/tge-labs/s2-stac-geoparquet) on Source Cooperative |
| Output | One COG (.tif) per box, about 10 m per pixel |
