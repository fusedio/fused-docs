# Fused Map

:::tip Using an AI agent?
Give your agent the [Fused Map skill](https://docs.fused.io/skills/FUSED_MAP.md) so it can inspect UDF outputs, choose the right layer types, and wire map parameters. For canvas and widget work in general, install the Workbench skills from [fusedio/skills](https://github.com/fusedio/skills). Or paste this prompt to build a small example map:

```text

```

Fused Map is a map widget in Fused. It draws geospatial data from a UDF, an `h3-query` widget or the H3 Data Retrieval REST API: points, polygons, H3 hexagons and raster tiles, with many layers on one map.

Its type is `fused-map`. It works like any other [widget](/guide/data-input-outputs/import-connection/widgets): configure it in JSON, connect UDFs with edges, and share it as a URL. To see working examples, open the [Fused Map example canvas](https://www.fused.io/canvas/fc_fused/map_widget_canvas). For the props, see the [Fused Map API reference](/widget-api/fused-map).

## Add a Fused Map widget

1. In the Workbench canvas, select the **Widget** icon in the toolbar.
2. In the **Widget configuration** panel, select **Preset**, then **Maps and geo**, then **Fused map**.
3. Connect the UDF node to the widget node with an edge.
4. In the JSON, set `udf` to the name of the UDF in double braces, for example `{{my_udf}}`.

For a faster way, drag an edge from the output handle of a UDF node to an empty spot on the canvas, then select **Fused map** in the menu. Workbench creates a Fused Map widget that is already connected to the UDF and draws its result.

![Drag an edge from a UDF node and select Fused map](/img/widgets/fused-map-drag-node.gif)

:::note
The UDF must be on the same canvas. The name in `{{ }}` must match the UDF name exactly, with the same case.
:::

## Get data onto the map

Each layer reads its rows from one of three sources:

| Source | Set on the layer | Use it for |
|---|---|---|
| A UDF | `"udf": "{{my_udf}}"` | Anything a UDF returns: points, polygons, H3 cells or a raster image. |
| An [`h3-query`](/widget-api/h3-query) widget | `"data": "{{name}}"`, with an edge from the `h3-query` node to the map | The rows of one query on an [indexed H3 dataset](/guide/h3-analytics/data-retrieval-service), loaded in the browser. |
| The [H3 Data Retrieval](/guide/h3-analytics/data-retrieval-service) REST API | `"type": "fused-hex"` and `"source": {"path": "<dataset>"}` | A whole indexed dataset, read through [`GET /h3/query`](/rest-api/h3) one tile at a time, with no UDF. |

[H3 Visualization](/guide/h3-analytics/visualization) has working examples of the `h3-query` and `fused-hex` sources, and the [Fused Map API reference](/widget-api/fused-map) lists every layer type and prop.

To pass a widget input's value to a UDF, write `{{my_udf?<udf_argument>=$<param>}}`, where `<param>` is the input's `param` name. For example, `"udf": "{{my_udf?band_index=$band}}"` passes the value of an input whose `param` is `band` to the UDF's `band_index` argument, and runs the UDF again when it changes.

### Load a UDF per tile

:::important Name the first argument `bounds` to load data per tile
With `tile: true`, the map passes each tile's area as `[west, south, east, north]` in `EPSG:4326`. Return only the rows inside `bounds`. The type doesn't matter, only the name.

```python
@fused.udf
def udf(bounds):
    ...
```
:::

| `tile` | First argument is `bounds` | Result |
|---|---|---|
| `true` | Yes | Each tile gets its own data. |
| `true` | No | Every tile gets the same result. |
| `false` | Either | The UDF runs once and `bounds` is ignored. |

The raster layer uses `tile: true`, so the first argument is `bounds`.

```python
@fused.udf
def udf(
    bounds: fused.types.Bounds = [-122.6, 37.2, -121.7, 38.0],
    path: str = "s3://fused-asset/demos/seismic_data/v2023_1_pga_475_rock_3min.tif",
):
    common = fused.load("https://github.com/fusedio/udfs/tree/fbf5682/public/common/")
    tile = common.get_tiles(bounds, zoom=common.estimate_zoom(bounds))
    arr = common.read_tiff(tile, input_tiff_path=path)
    return common.arr_to_plasma(arr.filled(0), min_max=(0, 1.5))
```

```python
@fused.udf
def udf(path: str = "s3://fused-sample/demo_data/airbnb_listings_sf.parquet"):
    import geopandas as gpd
    import pandas as pd

    df = pd.read_parquet(path)
    df = df.dropna(subset=["latitude", "longitude", "price_in_dollar"])
    gdf = gpd.GeoDataFrame(
        df[["name", "neighbourhood_cleansed", "room_type", "price_in_dollar"]],
        geometry=gpd.points_from_xy(df["longitude"], df["latitude"]),
        crs="EPSG:4326",
    )
    return gdf
```

## Send map values to other widgets

A map can send its viewport bounds (`param`), the clicked feature (`clickParam`), the hovered feature (`hoverParam`), its box selection (`selectParam`), its camera (`stateParam`) and a per-layer row version (`sourceParam`) to canvas parameters. Other widgets and UDFs read them as `$<name>`. See the [Fused Map API reference](/widget-api/fused-map) for each one.

These three maps share `"stateParam": "nl_view"`. A pan or zoom on one map writes its camera to `nl_view`, and the other two read it, so the maps move together. Each runs the same `nightlights` UDF with a different `year`, which reads a cloud-optimized GeoTIFF of night lights one tile at a time.

```python
@fused.udf(cache_max_age="30d")
def udf(
    bounds: fused.types.Bounds = [67.5, 8.0, 90.0, 33.0],
    year: int = 2021,
    floor: float = 4.0,
    vmax: float = 200.0,
):
    import numpy as np
    import rasterio
    from rasterio.enums import Resampling
    from rasterio.vrt import WarpedVRT
    from rasterio.warp import transform_bounds
    from rasterio.transform import from_bounds

    url = (
        "https://s3.openlandmap.org/arco/"
        f"nightlights.average_viirs.v21_m_500m_s_{year}0101_{year}1231_go_epsg.4326_v20230823.tif"
    )
    west, south, east, north = transform_bounds("EPSG:4326", "EPSG:3857", *bounds)
    tile = from_bounds(west, south, east, north, 256, 256)
    with rasterio.open(url) as src:
        with WarpedVRT(src, crs="EPSG:3857", transform=tile, width=256, height=256, resampling=Resampling.bilinear, nodata=0) as vrt:
            v = vrt.read(1).astype("float32")

    t = np.clip((v - floor) / (vmax - floor), 0, 1) ** 0.5
    stops = np.array([[20, 20, 40], [110, 60, 20], [255, 170, 60], [255, 225, 150], [255, 250, 235]], np.float32)
    pos = t * (len(stops) - 1)
    i0 = np.clip(pos.astype(int), 0, len(stops) - 2)
    rgb = stops[i0] * (1 - (pos - i0)[..., None]) + stops[i0 + 1] * (pos - i0)[..., None]
    alpha = np.where(v > floor, 40 + 215 * t, 0)
    return np.dstack([rgb, alpha]).astype(np.uint8).transpose(2, 0, 1)
```

## The sidebar

The sidebar lists the map's layers. For each one, the viewer can change the type, the style, the filters and the SQL in the browser. Each layer has a **Style** tab and a **Filters** tab. In **Style**, set the layer type, the fill mode (for example **By value** with a property, a palette, steps, and a domain), the stroke, and the opacity.

![The Fused Map sidebar next to the map and the widget configuration](/img/widgets/fused-map-sidebar.jpg)

These changes are temporary. To keep them, select **Save to widget** to write them into the widget configuration, or select **Copy config** and paste the result into the JSON. Select **Reset** to undo the changes.
