# Fused Map

Fused Map is a widget that shows geospatial data on an interactive map. It draws data from a UDF, from a SQL query, or from a tile URL. Use it for H3 hexagons, vector features, and raster tiles.

Fused Map is a widget of type `fused-map`. For the general widget concepts, see [Widgets](/guide/data-input-outputs/import-connection/widgets). For the full list of props, see the [Fused Map API reference](/widget-api/fused-map).

With Fused Map, you can:

- **Show a UDF result** — Add a layer that points to a UDF. The map draws the result.
- **Load data per tile** — Set `tile: true`. The UDF runs once for each map tile, and only the visible area loads.
- **Query with SQL** — Run DuckDB SQL on a UDF result before the map draws it.
- **Restyle in the browser** — Use the sidebar to change colors, filters, and queries without a code change.

To see a full example, open the [Fused Map example canvas](https://unstable.fused.io/workbench/aman/map_experiments_mvt).

## Add a Fused Map widget

1. In the Workbench canvas, select the **Widget** icon in the toolbar.
2. In the **Widget configuration** panel, select **Preset**, then **Maps and geo**, then **Fused map**.
3. Connect the UDF node to the widget node with an edge.
4. In the JSON, set `udf` to the name of the UDF in double braces, for example `{{my_udf}}`.

The smallest Fused Map widget has one layer:

```json
{
  "type": "fused-map",
  "props": {
    "layers": [
      {
        "id": "my_layer",
        "type": "geojson",
        "udf": "{{my_udf}}",
        "tooltip": true
      }
    ]
  }
}
```

:::note
The UDF must be on the same canvas. The name in `{{ }}` must match the UDF name exactly, with the same case.
:::

## Layer types

Set the `type` of each layer to one of these values.

| Type | Use it for | Data source |
|---|---|---|
| `geojson` | Points, lines, and polygons | `udf`, `sql`, or `data` |
| `h3` | H3 hexagons | `udf` or `sql` with an H3 column |
| `raster` | Images, such as satellite data or model output | `udf` with `tile: true`, or `tileUrl` |
| `mvt` | Pre-built vector tiles | `tileUrl` |
| `heatmap` | Point density | `udf` or `sql` |
| `scatterplot` | Points with a radius | `udf` or `sql` |
| `arc` | Arcs | `udf` or `sql` |
| `deck-geojson` | GeoJSON with 3D extrusion | `udf`, `sql`, or `data` |

A map can have many layers. The map draws them in the order of the `layers` array.

## Load data

A layer reads data in one of four ways. Use only one of `udf`, `sql`, `data`, or `tileUrl` for each layer.

| Property | What the map does |
|---|---|
| `udf` | Runs the UDF one time and draws the whole result. |
| `udf` and `tile: true` | Runs the UDF for each map tile. The UDF gets the tile `bounds`. |
| `sql` | Runs a DuckDB query on a UDF result, then draws the rows. |
| `tileUrl` | Reads tiles from a URL with `{z}`, `{x}`, and `{y}` placeholders. |

### What the UDF returns

The type of the layer sets what the UDF must return.

| Layer type | The UDF returns |
|---|---|
| `geojson`, `deck-geojson` | A GeoDataFrame in `EPSG:4326`. Or a DataFrame with a latitude column and a longitude column. Set `latColumn` and `lngColumn`. |
| `h3` | A DataFrame with a column of H3 cell IDs. Set `h3Column` to the column name. |
| `raster` | An image array, one tile at a time. |

Every other column in the result is a property of the feature. The tooltip, the filters, and the data-driven colors use these properties.

### What the UDF receives in tile mode

If `tile` is `true`, the map calls the UDF for each tile. The map sends the tile area in the `bounds` argument. The format is `[west, south, east, north]` in `EPSG:4326`.

Add `bounds: fused.types.Bounds` to the UDF arguments. Return only the rows inside `bounds`.

```python
@fused.udf
def udf(bounds: fused.types.Bounds = [-122.5, 37.7, -122.3, 37.85]):
    ...
```

:::warning
If the UDF has no `bounds` argument, every tile gets the same result.
:::

## H3 hexagons

This UDF reads a Source Coop file of US census data. The `hex` column in the file is an integer. The UDF changes it to the H3 string form, for example `872830828ffffff`. The map needs this form.

The `bounds` argument is optional:

- If you do not set `bounds`, the UDF returns rows from the whole file. The `limit` argument keeps about 100,000 rows, spread evenly across the file.
- If you set `bounds`, the UDF returns only the cells with a center inside `bounds`.

```python
@fused.udf
def udf(
    bounds: fused.types.Bounds = None,
    path: str = "s3://us-west-2.opendata.source.coop/fused/hex/release_2025_04_beta/census/2020_partitioned_h7.parquet",
    limit: int = 100000,
):
    import duckdb

    con = duckdb.connect()
    con.sql("INSTALL httpfs; LOAD httpfs;")
    con.sql("SET s3_region='us-west-2'; SET s3_url_style='path';")

    where = "TRUE"
    if bounds:
        west, south, east, north = [float(v) for v in bounds]
        con.sql("INSTALL h3 FROM community; LOAD h3;")
        where = f"""h3_cell_to_lng(hex) BETWEEN {west} AND {east}
                    AND h3_cell_to_lat(hex) BETWEEN {south} AND {north}"""
    elif limit:
        total = con.sql(f"SELECT count(*) FROM read_parquet('{path}')").fetchone()[0]
        step = max(1, total // int(limit))
        where = f"file_row_number % {step} = 0"

    df = con.sql(f"""
        SELECT lower(printf('%x', hex)) AS hex, state, county, POP20, HOUSING20
        FROM read_parquet('{path}', file_row_number=true)
        WHERE {where}
    """).df()
    return df
```

:::note
The bucket name has dots in it. Set `s3_url_style` to `path` so that DuckDB can connect.
:::

### Without tiles

Connect the UDF to a widget node. Name the UDF `source_coop_hex`. The map calls the UDF one time and draws the sample.

```json
{
  "type": "fused-map",
  "props": {
    "centerLng": -98,
    "centerLat": 39.5,
    "zoom": 3,
    "layers": [
      {
        "id": "hex",
        "name": "Census hex",
        "type": "h3",
        "udf": "{{source_coop_hex}}",
        "h3Column": "hex",
        "tooltip": ["hex", "state", "county", "POP20", "HOUSING20"],
        "legend": { "title": "POP20" },
        "style": {
          "fillColor": {
            "type": "continuous",
            "attr": "POP20",
            "palette": "Sunset",
            "domain": [0, 500]
          },
          "opacity": 0.8,
          "coverage": 0.9
        }
      }
    ]
  }
}
```

### With tiles

Add `tile: true`. The map calls the UDF for each tile and sends `bounds`. Each call returns only the cells in the tile.

```json
{
  "type": "fused-map",
  "props": {
    "centerLng": -122.4,
    "centerLat": 37.77,
    "zoom": 8,
    "autoFit": false,
    "layers": [
      {
        "id": "hex",
        "name": "Census hex (tiled)",
        "type": "h3",
        "udf": "{{source_coop_hex}}",
        "tile": true,
        "h3Column": "hex",
        "tooltip": ["hex", "state", "county", "POP20", "HOUSING20"],
        "style": {
          "fillColor": {
            "type": "continuous",
            "attr": "POP20",
            "palette": "Sunset",
            "domain": [0, 500]
          },
          "opacity": 0.8,
          "coverage": 0.9
        }
      }
    ]
  }
}
```

## Vector tiles

Use a `geojson` layer with `tile: true` to load a large vector table. This UDF reads Microsoft building footprints. The `table_to_tile` helper returns only the buildings in `bounds`.

```python
@fused.udf
def udf(
    bounds: fused.types.Bounds = [-122.446, 37.756, -122.430, 37.770],
    table_path: str = "s3://fused-asset/infra/building_msft_us",
):
    common = fused.load("https://github.com/fusedio/udfs/tree/fbf5682/public/common/")
    return common.table_to_tile(bounds, table=table_path)
```

Name the UDF `sf_buildings_tile`.

```json
{
  "type": "fused-map",
  "props": {
    "centerLng": -122.44,
    "centerLat": 37.76,
    "zoom": 13,
    "autoFit": false,
    "layers": [
      {
        "id": "buildings",
        "name": "SF buildings",
        "type": "geojson",
        "udf": "{{sf_buildings_tile}}",
        "tile": true,
        "minZoom": 12,
        "maxZoom": 18,
        "tooltip": true,
        "style": {
          "fillColor": {
            "type": "continuous",
            "attr": "num_rows",
            "palette": "Sunset",
            "domain": [0, 80000]
          },
          "lineColor": [255, 255, 255],
          "lineWidth": 1,
          "opacity": 0.8
        }
      }
    ]
  }
}
```

If you already have vector tiles on a server, use an `mvt` layer. Set `sourceLayer` if the tiles do not use the layer name `default`.

```json
{
  "type": "fused-map",
  "props": {
    "layers": [
      {
        "id": "counties",
        "type": "mvt",
        "tileUrl": "https://tiles.fused.io/public/my_tileset/{z}/{x}/{y}",
        "style": { "fillColor": [100, 150, 200], "opacity": 0.6 }
      }
    ]
  }
}
```

## Raster tiles

Use a `raster` layer with `tile: true` to show an image. The UDF reads the raster for `bounds` and returns an image array. This UDF shows a seismic hazard raster.

```python
@fused.udf
def udf(
    bounds: fused.types.Bounds = [-122.6, 37.2, -121.7, 38.0],
    path: str = "s3://fused-asset/demos/seismic_data/v2023_1_pga_475_rock_3min.tif",
):
    common = fused.load("https://github.com/fusedio/udfs/tree/fbf5682/public/common/")
    tile = common.get_tiles(bounds, zoom=common.estimate_zoom(bounds))
    arr = common.read_tiff(tile, input_tiff_path=path)
    return common.arr_to_plasma(arr.filled(0), min_max=(0, 1.5))
```

Name the UDF `seismic_raster`.

```json
{
  "type": "fused-map",
  "props": {
    "centerLng": -122.2,
    "centerLat": 37.6,
    "zoom": 8.5,
    "autoFit": false,
    "layers": [
      {
        "id": "seismic",
        "name": "Seismic hazard",
        "type": "raster",
        "udf": "{{seismic_raster}}",
        "tile": true,
        "style": { "opacity": 0.8 }
      }
    ]
  }
}
```

:::note
For a raster layer from a `tileUrl`, only `opacity` and `visible` apply.
:::

## Query a UDF with SQL

Use `sql` to filter or reshape a UDF result before the map draws it. Use `{{udf_name}}` in the query. The map runs the query in the browser with DuckDB.

This UDF returns a DataFrame with latitude and longitude columns. Name it `sf_listings`.

```python
@fused.udf
def udf():
    import pandas as pd

    path = "s3://fused-sample/demo_data/airbnb_listings_sf.parquet"
    df = pd.read_parquet(path).dropna(subset=["latitude", "longitude", "price_in_dollar"])
    return df[["name", "latitude", "longitude", "price_in_dollar", "room_type"]]
```

Set `latColumn` and `lngColumn` to draw the rows as points. Add a range filter to let the user limit the price in the sidebar.

```json
{
  "type": "fused-map",
  "props": {
    "basemap": "mapbox://styles/mapbox/dark-v11",
    "centerLng": -122.43,
    "centerLat": 37.76,
    "zoom": 11,
    "layers": [
      {
        "id": "listings",
        "type": "geojson",
        "sql": "SELECT name, latitude, longitude, price_in_dollar FROM {{sf_listings}}",
        "latColumn": "latitude",
        "lngColumn": "longitude",
        "tooltip": ["name", "price_in_dollar"],
        "filters": [
          { "attr": "price_in_dollar", "type": "range", "min": 0, "max": 1000 }
        ],
        "style": { "fillColor": [232, 255, 89], "pointRadius": 2 }
      }
    ]
  }
}
```

If the result has a geometry column, set `geometryColumn`. The column can hold GeoJSON strings, GeoJSON objects, or WKB.

## Style, tooltip, legend, and filters

Use these properties on a layer to change how it looks.

### Style

The `style` object sets the colors and shapes.

| Property | Description |
|---|---|
| `fillColor` | A color `[r, g, b]`, a CSS color string, or a data-driven color. |
| `lineColor` | A stroke color. Same formats as `fillColor`. |
| `lineWidth` | The stroke width in pixels. |
| `opacity` | The layer opacity, from 0 to 1. |
| `pointRadius` | The circle radius for points. |
| `coverage` | The H3 cell size, from 0 to 1. A value of 1 leaves no gap. |
| `extruded` | Set to `true` for 3D height on `h3` and `deck-geojson` layers. |
| `elevationAttr` | The property that sets the 3D height. |
| `elevationScale` | A multiplier for the 3D height. |

A data-driven color uses a property of the feature:

```json
{
  "fillColor": {
    "type": "continuous",
    "attr": "height",
    "palette": "Sunset",
    "domain": [0, 100]
  }
}
```

Use `"type": "categorical"` for properties with a set of values.

### Tooltip and legend

- Set `tooltip` to `true` to show all properties. Set it to a list of names to show only those properties.
- Set `legend` to `true` for an automatic title, or to `{ "title": "My title" }`. The legend shows only for data-driven colors.

### Filters

`filters` limit the features on the client. There are two types:

```json
[
  { "attr": "price_in_dollar", "type": "range", "min": 0, "max": 500 },
  { "attr": "room_type", "type": "categories", "values": ["Entire home/apt"] }
]
```

## The sidebar

The sidebar lets the viewer change the style, the filters, and the SQL of each layer in the browser. These changes are temporary. To keep them, use the copy action in the sidebar and paste the result into the widget configuration.

To hide the sidebar, set `showSidebar` to `false`.

## Share the map state

Three props connect the map to other widgets on the canvas.

| Prop | What it does |
|---|---|
| `param` | Writes the visible bounds `[west, south, east, north]` to a canvas parameter. |
| `clickParam` | Writes the properties of the last clicked feature to a canvas parameter. |
| `stateParam` | Writes the map state to a canvas parameter. The state includes the camera, the layer styles, the filters, and the SQL changes. The canvas saves it. |

Set `autoSend` to `true` to send the bounds when the user pans or zooms. `autoSendDebounceMs` sets the wait time in milliseconds.

## Map props

| Prop | Type | Default | Description |
|---|---|---|---|
| `layers` | array | `[]` | The layers to draw. |
| `basemap` | string | `mapbox://styles/mapbox/dark-v11` | The Mapbox style URL. |
| `centerLng`, `centerLat` | number | | The center of the map. If you set one, `autoFit` is off unless you set it. |
| `zoom` | number | `4` | The start zoom level. |
| `minZoom`, `maxZoom` | number | | The zoom limits, from 0 to 24. |
| `autoFit` | boolean | `true` | Fly to the loaded data one time. Tile layers do not report bounds, so set `centerLng`, `centerLat`, and `zoom` for them. |
| `showControls` | boolean | `true` | Show the zoom buttons. |
| `showScale` | boolean | `true` | Show the scale bar. |
| `showBasemapSwitcher` | boolean | `true` | Show the dark, light, and satellite switch. |
| `showLegend` | boolean | `true` | Show the legend for data-driven colors. |
| `showLayerPanel` | boolean | `true` | Show the panel to turn layers on and off and change opacity. |
| `showSidebar` | boolean | `true` | Show the sidebar. |
| `param` | string | | Canvas parameter for the visible bounds. |
| `clickParam` | string | | Canvas parameter for the clicked feature. |
| `stateParam` | string | | Canvas parameter for the map state. |
| `autoSend` | boolean | `false` | Send the bounds when the user pans or zooms. |
| `autoSendDebounceMs` | number | `600` | The wait time before the bounds are sent. |
| `style` | string | | CSS for the map container. |

## Layer props

| Prop | Type | Description |
|---|---|---|
| `id` | string | **Required.** A unique name for the layer. |
| `type` | string | **Required.** One of the [layer types](#layer-types). |
| `name` | string | The name in the layer panel. |
| `visible` | boolean | Show or hide the layer. The default is `true`. |
| `udf` | string | A UDF in double braces, for example `{{my_udf}}`. You can add arguments: `{{my_udf?param=value}}`. |
| `tile` | boolean | With `udf`, run the UDF for each map tile. |
| `sql` | string | A DuckDB query with `{{udf_name}}` placeholders. |
| `data` | object | An inline GeoJSON FeatureCollection. |
| `tileUrl` | string | A tile URL with `{z}`, `{x}`, and `{y}`. Do not use it with `udf`. |
| `sourceLayer` | string | The layer name inside MVT tiles. The default is `default`. |
| `minZoom`, `maxZoom` | number | The zoom limits for tiled layers. |
| `zoomOffset` | number | A zoom offset for tiled layers. Use it for hex tile generalization. |
| `maxRequests` | number | The maximum number of tile requests at the same time. |
| `geometryColumn` | string | The geometry column. The default is `geometry`. |
| `h3Column` | string | The column with H3 cell IDs. |
| `latColumn`, `lngColumn` | string | The point columns. The defaults are `lat` and `lng`. |
| `tooltip` | boolean or array | Show all properties, or only the listed ones. |
| `legend` | boolean or object | Show a legend. Set a title with `{ "title": "..." }`. |
| `style` | object | The [style](#style) of the layer. |
| `filters` | array | The [filters](#filters) for the layer. |
