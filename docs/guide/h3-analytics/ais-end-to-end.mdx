# End to End Example with AIS Ship Positions

This page walks through a full [H3 Data Retrieval Service](/guide/h3-analytics/data-retrieval-service) pipeline on a large dataset: **1.12 billion ship positions** in US waters, July to October 2024. We download NOAA's daily files, partition them into H3 files by day, index them, then query them from a UDF and straight from [`GET /h3/query`](/rest-api/h3). The canvas UDFs that start jobs are [guarded](/guide/h3-analytics/data-retrieval-end-to-end#partition), so opening the canvas never starts one. To learn the steps on a small dataset first, see [Partition, Index and Query](/guide/h3-analytics/data-retrieval-end-to-end).

![H3_AIS_Workflow canvas: download NOAA AIS zips, partition and index them into H3, query them from a UDF, map them from /h3/query, and replay ships in 3D](/img/tutorials/geospatial/h3/h3_ais_workflow_canvas.png)

_The [H3_AIS_Workflow canvas](https://www.fused.io/canvas/fc_1HgBSCdgNIItDo9Y0OpZzz) has five sections: download, partition and index, a UDF query, maps on `/h3/query` and a 3D ship replay. Open it to run any of them._

- **Source:** [NOAA AIS](https://hub.marinecadastre.gov/pages/vesseltraffic) daily files, every vessel position report off US coasts
- **Time range:** 2024-07-01 to 2024-10-31, 123 days. NOAA's files for October 18, 19 and 27 are corrupt, so 120 days are partitioned.
- **H3 settings:** each report gets the H3 cell at resolution 10 that holds its position, and the data is partitioned by date, one folder per day
- **Public copy:** the result is indexed at `s3://fused-asset/data/ais/ais_week_h3_v2/` and anyone can read it. To only query, skip to [step 4](#4-query).

## 1. Download

NOAA publishes one zip per day, about 290 to 410 MB each, at `https://coast.noaa.gov/htdata/CMSP/AISDataHandler/2024/AIS_2024_07_01.zip`. A UDF copies the zips as they are to [Fused storage](/python-sdk/api-reference/api#upload), all days at once, and skips the days already there.

**Returns:** one row per day with its status and size. Two days take about 90 seconds.

<details>
<summary>Code</summary>

```python showLineNumbers
@fused.udf(cache_max_age=0)
def udf(days: list = ["2024-07-01", "2024-07-02"], raw: str = "fd://ais_raw/"):
    from concurrent.futures import ThreadPoolExecutor

    import fsspec
    import pandas as pd
    import requests

    fs = fsspec.filesystem("s3")
    folder = fused.api.resolve(raw).rstrip("/")

    def copy(day):
        name = f"AIS_{day.replace('-', '_')}.zip"
        dest = f"{folder}/{name}"
        if fs.exists(dest):
            return {"day": day, "status": "already there"}
        url = f"https://coast.noaa.gov/htdata/CMSP/AISDataHandler/{day[:4]}/{name}"
        with requests.get(url, stream=True, timeout=300) as r:
            r.raise_for_status()
            with fs.open(f"{dest}.part", "wb") as out:
                for chunk in r.iter_content(1 << 23):
                    out.write(chunk)
        fs.mv(f"{dest}.part", dest)
        return {"day": day, "status": "downloaded", "MB": round(fs.size(dest) / 1e6)}

    with ThreadPoolExecutor(len(days)) as pool:
        return pd.DataFrame(list(pool.map(copy, days)))
```

</details>

## 2. Partition

- **Source:** each zip holds a CSV, so a UDF reads one day and adds a `date` column. Partition runs it with [`fused.h3.sources.udf`](/python-sdk/api-reference/h3#sourcesudf).
- **Resolution:** 10. Each cell has an edge of about 76 m, small enough to tell ships apart in a harbor (see the [Resolution Guide](/guide/h3-analytics/resolution-guide)).
- **Partitioned by date:** one folder per day, and each day is its own job. A day is about 9 to 10 million rows and takes about a minute to read on `m5.xlarge`.
- **Running again:** days already written are skipped, and `redo=True` rewrites the days you pass; see [Running again](/guide/h3-analytics/data-retrieval-end-to-end#running-again).

**Writes:** one folder per day, with one Parquet file per large H3 cell inside it. The UDF returns the run id at once; two days finish in about 5 minutes.

```text
ais_h3/
├── date=2024-07-01/
│   ├── 81033ffffffffff.parquet
│   └── ...
├── date=2024-07-02/
│   └── ...
└── _manifest.json
```

<details>
<summary>Code</summary>

```python showLineNumbers
@fused.udf(cache_max_age=0)
def udf(days: list = ["2024-07-01", "2024-07-02"], raw: str = "fd://ais_raw/", out: str = "fd://ais_h3/"):
    @fused.udf
    def read_day(date: str, raw: str):
        import zipfile

        import fsspec
        import numpy as np
        import pyarrow as pa
        import pyarrow.compute as pc
        import pyarrow.csv as pacsv

        types = {
            "MMSI": pa.int64(), "BaseDateTime": pa.timestamp("s"),
            "LAT": pa.float64(), "LON": pa.float64(), "SOG": pa.float64(), "COG": pa.float64(), "Heading": pa.float64(),
            "VesselName": pa.string(), "IMO": pa.string(), "CallSign": pa.string(),
            "VesselType": pa.float64(), "Status": pa.float64(), "Length": pa.float64(), "Width": pa.float64(),
            "Draft": pa.float64(), "Cargo": pa.float64(), "TransceiverClass": pa.string(),
        }
        zip_path = f"{fused.api.resolve(raw).rstrip('/')}/AIS_{date.replace('-', '_')}.zip"
        with fsspec.open(zip_path, "rb") as f, zipfile.ZipFile(f) as z, z.open(z.namelist()[0]) as csv:
            table = pacsv.read_csv(csv, convert_options=pacsv.ConvertOptions(column_types=types))
        lat, lon = table["LAT"], table["LON"]
        valid = pc.and_(
            pc.and_(pc.is_valid(lat), pc.is_valid(lon)),
            pc.and_(pc.and_(pc.greater_equal(lat, -90), pc.less_equal(lat, 90)), pc.and_(pc.greater_equal(lon, -180), pc.less_equal(lon, 180))),
        )
        table = table.filter(valid)
        return table.append_column("date", pa.array(np.full(table.num_rows, np.datetime64(date, "D")), pa.date32()))

    run = fused.h3.partition(
        fused.h3.sources.udf(read_day, raw=raw),
        out,
        partition_by={"date": days},
        point_column=("LAT", "LON"),
        h3_res=10,
        file_res=1,
        read_engine="m5.xlarge",
        engine="m5.xlarge",
    )
    return run.id
```

</details>

## 3. Index

- **What it records:** the cells, dates and time range each file covers, so a query reads only the files it needs.
- **Columns:** `hex` for the H3 cell, `BaseDateTime` for time, `date` for the partition.
- **Parallel:** the 120 day folders are split into 12 slices that index at once.
- **Running again:** indexes only new or changed days; `redo=True` reads every day again. See [`fused.h3.index`](/python-sdk/api-reference/h3#index).

**Returns:** the run id at once. The status of the public copy, from [`fused.h3.index_status`](/python-sdk/api-reference/h3#index_status):

| Field | Value |
|---|---|
| Status | `ready` |
| Files | 6,880 |
| Resolution | 10 |
| Time range | 2024-07-01 to 2024-10-31 |
| `date` values | 120 |

<details>
<summary>Code</summary>

```python
@fused.udf(cache_max_age=0)
def udf(path: str = "fd://ais_h3/"):
    run = fused.h3.index(path, time_column="BaseDateTime", options={"instances": 12})
    return run.id
```

## 4. Query

A UDF calls [`fused.h3.query`](/python-sdk/api-reference/h3#query) with the map view ([`bounds`](/python-sdk/api-reference/fused-types#bounds)) and a UTC time window, and returns every report inside them. A widget next to it sends the view and the window as you pan.

**Returns:** 6,214 reports from 194 vessels in New York Harbor for one hour, in 0.1 seconds. The whole day, 2024-07-03, returns 126,828 reports from 422 vessels in 0.13 seconds.

<details>
<summary>Code</summary>

```python
@fused.udf
def udf():
    return fused.h3.query(
        "s3://fused-asset/data/ais/ais_week_h3_v2/",
        bbox=(-74.10, 40.55, -73.90, 40.72),
        time_min="2024-07-03T12:00:00",
        time_max="2024-07-03T12:59:59",
        columns=["MMSI", "BaseDateTime", "LAT", "LON", "SOG", "VesselName", "VesselType"],
    )
```

</details>

## 6. Map with a `fused-hex` layer

A [`fused-hex` layer](/guide/h3-analytics/visualization#fused-hex-layer) on a [Fused Map](/guide/data-input-outputs/import-connection/fused-map) draws the dataset with no code: it calls `GET /h3/query` for each tile in view and colours each res-10 cell by its number of reports in the time window. Add this layer to a `fused-map` widget's `layers`.
