# End to End Example with AIS Ship Positions

This page walks through a full [H3 Data Retrieval Service](/guide/h3-analytics/data-retrieval-service) pipeline on a large dataset: NOAA's ship positions in US waters, 7.3 to 10.5 million a day. The canvas has ingested **449 million positions** over 47 days of 2024 so far. We download NOAA's daily files, partition them into H3 files by day, index them, then query them from a UDF and straight from [`GET /h3/query`](/rest-api/h3). The canvas UDFs that start jobs are [guarded](/guide/h3-analytics/data-retrieval-end-to-end#partition), so opening the canvas never starts one. To learn the steps on a small dataset first, see [Partition, Index and Query](/guide/h3-analytics/data-retrieval-end-to-end).

![AIS_End_to_End_Workflow canvas: a read me, a Multi-day ingest folder that downloads, partitions and indexes the days you pick, a map of the ingested days, and an AIS pipeline page that runs every step](/img/tutorials/geospatial/h3/ais_end_to_end_canvas.png)

_The [AIS_End_to_End_Workflow canvas](https://www.fused.io/canvas/fc_fused/AIS_End_to_End_Workflow) runs these steps for any date range you pick. The **Multi-day ingest** folder has one UDF per step and a list of the days available, **4. Map of the ingested days** draws them, and the **AIS pipeline** page at the top runs every step from one place. The UDFs in steps 1 to 3 are short versions of the canvas UDFs._

- **Source:** [NOAA AIS](https://hub.marinecadastre.gov/pages/vesseltraffic) daily files, every vessel position report off US coasts
- **Days ingested:** 47 days between 2024-07-01 and 2024-12-06, picked in the canvas
- **H3 settings:** each report gets the H3 cell at resolution 10 that holds its position, and the data is partitioned by date, one folder per day
- **Public copy:** the canvas writes to `s3://fused-asset/data/ais/ais_multiday_ingest_v1/h3/`, indexed and readable by anyone. To only query, skip to [step 4](#4-query).

## 1. Download

NOAA publishes one zip per day, about 290 to 410 MB each, at `https://coast.noaa.gov/htdata/CMSP/AISDataHandler/2024/AIS_2024_07_01.zip`. A UDF downloads each day's zip, reads the CSV inside and saves it as Parquet on [Fused storage](/python-sdk/api-reference/api#upload), one `date=YYYY-MM-DD` folder per day. [`.map`](/python-sdk/api-reference/udf#map) runs one worker per day, and days already there are skipped. Partition then reads the Parquet directly, with no zip or CSV to parse.

**Returns:** one row per day with its status and row count. Two days take about 45 seconds.

<details>
<summary>Code</summary>

```python showLineNumbers
@fused.udf(cache_max_age=0)
def udf(days: list = ["2024-07-01", "2024-07-02"], raw: str = "fd://ais_raw/"):
    import fsspec
    import pandas as pd

    fs = fsspec.filesystem("s3")
    folder = fused.api.resolve(raw).rstrip("/")
    todo = [d for d in days if not fs.exists(f"{folder}/date={d}/")]
    there = pd.DataFrame({"date": [d for d in days if d not in todo], "status": "already there"})
    if not todo:
        return there
    done = download_day.map(todo, raw=folder).df()
    return pd.concat([there, done], ignore_index=True)


@fused.udf(cache_max_age=0)
def download_day(date: str, raw: str):
    import os
    import tempfile
    import zipfile

    import fsspec
    import pandas as pd
    import pyarrow as pa
    import pyarrow.compute as pc
    import pyarrow.csv as pacsv
    import pyarrow.parquet as pq
    import requests

    y, m, d = date.split("-")
    url = f"https://coast.noaa.gov/htdata/CMSP/AISDataHandler/{y}/AIS_{y}_{m}_{d}.zip"
    types = {
        "MMSI": pa.int64(), "BaseDateTime": pa.timestamp("s"),
        "LAT": pa.float64(), "LON": pa.float64(), "SOG": pa.float64(), "COG": pa.float64(), "Heading": pa.float64(),
        "VesselName": pa.string(), "IMO": pa.string(), "CallSign": pa.string(),
        "VesselType": pa.float64(), "Status": pa.float64(), "Length": pa.float64(), "Width": pa.float64(),
        "Draft": pa.float64(), "Cargo": pa.float64(), "TransceiverClass": pa.string(),
    }
    with tempfile.TemporaryDirectory() as tmp:
        zip_path = os.path.join(tmp, "day.zip")
        with requests.get(url, stream=True, timeout=300) as r:
            r.raise_for_status()
            with open(zip_path, "wb") as out:
                for chunk in r.iter_content(1 << 23):
                    out.write(chunk)
        with zipfile.ZipFile(zip_path) as z:
            table = pacsv.read_csv(z.open(z.namelist()[0]), convert_options=pacsv.ConvertOptions(column_types=types))
    table = table.filter(pc.and_(pc.less_equal(pc.abs(table["LAT"]), 90), pc.less_equal(pc.abs(table["LON"]), 180)))
    with fsspec.open(f"{raw}/date={date}/AIS_{y}_{m}_{d}.parquet", "wb") as f:
        pq.write_table(table, f, compression="zstd", row_group_size=500_000)
    return pd.DataFrame([{"date": date, "status": "downloaded", "rows": table.num_rows}])
```

</details>

## 2. Partition

- **Source:** the Parquet from step 1, read with [`fused.h3.sources.parquet`](/python-sdk/api-reference/h3#sourcesparquet). `partition_by={"date": days}` reads one `date=` folder per job.
- **Resolution:** 10. Each cell has an edge of about 76 m, small enough to tell ships apart in a harbor (see the [Resolution Guide](/guide/h3-analytics/resolution-guide)).
- **Partitioned by date:** one folder per day, and each day is its own job, 7.3 to 10.5 million rows. `on_null_point="drop"` skips the reports with no position.
- **Running again:** days already written are skipped, and `redo=True` rewrites the days you pass; see [Running again](/guide/h3-analytics/data-retrieval-end-to-end#running-again).

**Writes:** one folder per day, with one Parquet file per large H3 cell inside it. The UDF returns the run id at once; two days finish in about 30 seconds on `realtime`.

```text
ais_h3/
├── date=2024-07-01/
│   ├── 81033ffffffffff.parquet
│   └── ...
├── date=2024-07-02/
│   └── ...
└── _manifest.json
```

<details>
<summary>Code</summary>

```python
@fused.udf(cache_max_age=0)
def udf(days: list = ["2024-07-01", "2024-07-02"], raw: str = "fd://ais_raw/", out: str = "fd://ais_h3/"):
    run = fused.h3.partition(
        fused.h3.sources.parquet(raw),
        out,
        partition_by={"date": days},
        point_column=("LAT", "LON"),
        h3_res=10,
        file_res=1,
        on_null_point="drop",
        engine="realtime",
    )
    return run.id
```

</details>

## 3. Index

- **What it records:** the cells, dates and time range each file covers, so a query reads only the files it needs.
- **Columns:** `hex` for the H3 cell, `BaseDateTime` for time, `date` for the partition.
- **Parallel:** the day folders are split into up to 12 slices that index at once.
- **Running again:** indexes only new or changed days; `redo=True` reads every day again. See [`fused.h3.index`](/python-sdk/api-reference/h3#index).

**Returns:** the run id at once. The status of the canvas's copy, from [`fused.h3.index_status`](/python-sdk/api-reference/h3#index_status):

| Field | Value |
|---|---|
| Status | `ready` |
| Files | 2,816 |
| Resolution | 10 |
| Time range | 2024-07-01 to 2024-12-06 |
| `date` values | 47 |

<details>
<summary>Code</summary>

```python
@fused.udf(cache_max_age=0)
def udf(path: str = "fd://ais_h3/"):
    run = fused.h3.index(path, time_column="BaseDateTime", options={"instances": 12})
    return run.id
```

## 4. Query

A UDF calls [`fused.h3.query`](/python-sdk/api-reference/h3#query) with an area and a UTC time window, and returns every report inside them.

**Returns:** 6,214 reports from 194 vessels in New York Harbor for one hour, in 0.14 seconds. The whole day, 2024-07-03, returns 126,828 reports from 422 vessels in 0.14 seconds.

<details>
<summary>Code</summary>

```python
@fused.udf
def udf():
    return fused.h3.query(
        "s3://fused-asset/data/ais/ais_multiday_ingest_v1/h3/",
        bbox=(-74.10, 40.55, -73.90, 40.72),
        time_min="2024-07-03T12:00:00",
        time_max="2024-07-03T12:59:59",
        columns=["MMSI", "BaseDateTime", "LAT", "LON", "SOG", "VesselName", "VesselType"],
    )
```

## 5. Map from `/h3/query`

The canvas's **4. Map of the ingested days** reads points straight from [`GET /h3/query`](/rest-api/h3) with an [`h3-query`](/widget-api/h3-query) widget, and draws them as a `scatterplot` layer on a [Fused Map](/guide/data-input-outputs/import-connection/fused-map), with no UDF. Pick a day on the calendar (yellow days are indexed) and a From/To window of up to 24 hours; panning loads the points in view. It reads the days ingested from the canvas, at `s3://fused-asset/data/ais/ais_multiday_ingest_v1/h3/`.

```python title="list_ais_days_available.py"
import fused

RAW = "s3://fused-asset/data/ais/ais_multiday_ingest_v1/raw/"
H3_PATH = "s3://fused-asset/data/ais/ais_multiday_ingest_v1/h3/"


@fused.udf(cache_max_age=0)
def udf(raw_s3_folder: str = RAW, h3_s3_folder: str = H3_PATH):
    """List every day an AIS ingest has touched and how far it got (the multi-day ingest by default).

    One row per day: downloaded (Parquet in raw_s3_folder), partitioned (in h3_s3_folder's
    manifest, with its row count) and indexed (readable by the map). `state` is the furthest
    step reached: "indexed" days can be viewed, "partitioned" days still need indexing,
    "downloaded" days still need partitioning. The calendar in the multi-day map reads this.
    """
    import json

    import fsspec
    import pandas as pd

    raw = raw_s3_folder.rstrip("/") + "/"
    h3_path = h3_s3_folder.rstrip("/") + "/"
    fs = fsspec.filesystem("s3")
    try:
        downloaded = {p.rstrip("/").rsplit("date=", 1)[-1] for p in fs.ls(raw, refresh=True) if "date=" in p}
    except FileNotFoundError:
        downloaded = set()

    try:
        with fs.open(f"{h3_path}_manifest.json") as f:
            folder_rows = json.load(f).get("folder_rows") or {}
    except FileNotFoundError:
        folder_rows = {}
    rows = {k.replace("date=", ""): v for k, v in folder_rows.items()}

    indexed = set()
    if fused.h3.index_status(h3_path):
        indexed = {p.split("date=", 1)[1].split("/", 1)[0] for p in fused.h3.indexed_files(h3_path) if "date=" in p}

    days = sorted(downloaded | set(rows) | indexed)
    return pd.DataFrame({
        "date": days,
        "state": ["indexed" if d in indexed else "partitioned" if d in rows else "downloaded" for d in days],
        "downloaded": [d in downloaded for d in days],
        "partitioned": [d in rows for d in days],
        "indexed": [d in indexed for d in days],
        "rows": pd.array([rows.get(d) for d in days], dtype="Int64"),
    })
```
