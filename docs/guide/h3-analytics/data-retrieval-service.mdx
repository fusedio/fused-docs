## How it works

- **Partition**: [`fused.h3.partition()`](/python-sdk/api-reference/h3#partition) writes your rows as H3 Parquet files. It takes a source, such as a UDF that returns your rows, not a DataFrame.
- **Index**: [`fused.h3.index()`](/python-sdk/api-reference/h3#index) records which cells each file covers, plus its partition values and time range.
- **Query**: [`fused.h3.query()`](/python-sdk/api-reference/h3#query) reads back only the rows you ask for, by area, point, cell, time window or partition value.
- **H3 query API**: [`GET /h3/query`](/rest-api/h3) runs the same query over HTTP, from any language or web page.

Needs `fused` 2.9.3 or later. Partition and index start a run and return; call `.wait()` to block until it finishes.

## Query a public dataset now

No account needed:

```bash
curl -G "https://www.fused.io/server/v1/h3/query" \
  --data-urlencode "path=s3://fused-asset/data/ais/ais_week_h3_v2/" \
  -d min_lng=-74.10 -d min_lat=40.55 -d max_lng=-73.90 -d max_lat=40.72 \
  -d time_min=2024-07-03T12:00:00 -d time_max=2024-07-03T12:59:59 \
  -o harbor.parquet
```

**Returns:** HTTP 200, a Parquet file with the 6,214 ship positions in New York Harbor for that hour. For your own dataset, add an [`Authorization` header](/rest-api/overview#authentication). Every parameter is in the [`GET /h3/query` reference](/rest-api/h3) and the [interactive API documentation](https://www.fused.io/server/docs).

## Tips

- **`partition_by`:** for nonspatial columns such as `date`, never location. `file_res` sets how much area one file covers.
- **Adding data:** partition only the new data with `append=True`, then index again without `overwrite`.
- **Exact edges:** a query matches whole cells. Pad the box by about one cell, then filter by latitude and longitude.
- **Large results:** HTTP 413 means one read is too large. Split the area or time window.
- **Very large datasets:** hundreds of GB or tens of thousands of files? Contact **info@fused.io**.
