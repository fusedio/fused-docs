# H3 Data Retrieval Service

The Fused H3 Data Retrieval Service ingests your data, even billions of rows, so you can retrieve any part of it quickly. It returns any area or time window within 2 seconds. New to H3? Start with [Working with H3](/guide/working-with-udfs/udf-best-practices/working-with-h3).

It takes three steps: partition, index, then query.

:::tip Using an AI agent?
Copy [this file](https://docs.fused.io/skills/H3.md) and pass it to your AI agent to partition, index and query your data. Or paste this prompt to get a demo canvas:

```text
Make sure the Fused CLI is installed. Read https://docs.fused.io/skills/H3.md and https://github.com/fusedio/skills. Then create a Workbench canvas named NYC311_H3 that partitions NYC 311 requests for 2024-07-04 into H3 on fd://, indexes them and maps each request as a point from the GET /h3/query endpoint. Push it and give me its URL.
```
:::

## Workflow

| Step | What it does | Reference |
|---|---|---|
| **Partition** | Writes your rows as H3 Parquet files, in folders by the values you filter on. Takes a source, such as a UDF that returns your rows. | [`fused.h3.partition()`](/python-sdk/api-reference/h3#partition) |
| **Index** | Records which cells, partition values and times each file covers | [`fused.h3.index()`](/python-sdk/api-reference/h3#index) |
| **Query in a UDF** | Reads back only the rows you ask for, by area, point, cell, time window or partition value. Runs only inside a UDF on Fused. | [`fused.h3.query()`](/python-sdk/api-reference/h3#query) |
| **Query over HTTP** | The same query as an endpoint that returns Parquet, for any language or web page | [`GET /h3/query`](/rest-api/h3) |
| **Visualize** | Draws the dataset on a map with the [Fused Map](/guide/data-input-outputs/import-connection/fused-map) widget and a layer of type [`fused-hex`](/guide/h3-analytics/visualization#fused-hex-layer), with no UDF | [H3 Visualization](/guide/h3-analytics/visualization) |
