# Ingest, Index & Query H3 Datasets

`fused.h3` turns your data into a **hex dataset** you can query by point, area, cell or time without scanning every file. It takes three steps:

1. **Partition**: [`fused.h3.partition()`](/python-sdk/api-reference/h3#partition) writes your rows as H3-sorted Parquet files.
2. **Index**: [`fused.h3.index()`](/python-sdk/api-reference/h3#index) registers the dataset with Fused.
3. **Query**: [`fused.h3.query()`](/python-sdk/api-reference/h3#query) reads back only the rows you ask for.

Use it for large datasets of any type: points, vectors, tables and multi-dimensional data such as weather. It partitions and indexes your data; any conversion or aggregation, such as averaging raster pixels per hex, is yours to do before partitioning. For rasters where you want aggregation and overviews built in, use the [raster ingestion pipeline](/guide/h3-analytics/raster-ingestion). See [Choose your path](/guide/h3-analytics/h3-overview#choose-your-path).

A query reads only the part you ask for, so the benefit grows with the dataset. The examples below ingest [10.4 million NYC 311 requests](#example-41-months-of-nyc-311-requests), and over 300 million rows each of [AIS](#example-one-month-of-ais-ship-positions) and [LiDAR](#example-every-lidar-point-in-manhattan).

:::note Don't use `partition_by` for location
`partition()` already groups rows by location; use `file_res` to adjust file coverage. Use `partition_by` for nonspatial columns, such as `date`, `hour` or `scenario`.
:::

The canvas's first step copies the NYC Open Data API to `raw`, one Parquet file per month. The partition step streams every month into one `partition()` call:

```python showLineNumbers {21-29}
@fused.udf(engine="medium")
def udf(
    raw: str = "fd://h3/nyc311_raw/",
    out: str = "fd://h3/nyc311/",
):
    import pandas as pd
    import pyarrow as pa
    import pyarrow.compute as pc

    files = sorted(p for p in fused.api.list(raw) if p.endswith(".parquet"))

    # 1. Source: every month's file, in batches, tagged with its month
    def batches():
        for path in files:
            month = path.rsplit("/", 1)[-1].removesuffix(".parquet")  # "2023-05"
            for batch in fused.h3.sources.parquet(path):
                batch = batch.filter(pc.and_(pc.is_valid(batch["latitude"]), pc.is_valid(batch["longitude"])))
                yield batch.append_column("month", pa.array([month] * batch.num_rows, pa.string()))

    # 2. Partition: one folder per month, one file per res-5 cell, each request as a res-11 hex
    fused.h3.partition(
        batches(),
        out,
        point_column=("latitude", "longitude"),
        h3_res=11,
        file_res=5,
        partition_by="month",
        overwrite=True,
    )
    return pd.DataFrame({"months": [len(files)]})
```

Index it with `created_date` as the time column:

```python showLineNumbers
@fused.udf
def udf(out: str = "fd://h3/nyc311/"):
    fused.h3.index(out, time_column="created_date", overwrite=True, wait=False)
```

Then query any area and month:

```python showLineNumbers
@fused.udf
def udf(out: str = "fd://h3/nyc311/"):
    # Every request in a few blocks of Midtown in May 2023
    return fused.h3.query(
        out,
        bbox=(-73.990, 40.752, -73.980, 40.760),
        partition={"month": "2023-05"},
        columns=["latitude", "longitude", "complaint_type", "created_date"],
    )
```

The canvas's first step copies NOAA's daily zips to `raw` as they are. The partition step then reads one day at a time and passes each day to `partition()` as one batch:

```python showLineNumbers {38-46}
@fused.udf(engine="m5.xlarge")
def udf(
    start_date: str = "2024-07-01",
    end_date: str = "2024-08-01",
    raw: str = "fd://h3/ais_raw/",
    out: str = "fd://h3/ais_july_2024/",
):
    import zipfile

    import fsspec
    import numpy as np
    import pandas as pd
    import pyarrow as pa
    import pyarrow.compute as pc
    import pyarrow.csv as pacsv

    types = {
        "MMSI": pa.int64(), "BaseDateTime": pa.timestamp("s"),
        "LAT": pa.float64(), "LON": pa.float64(), "SOG": pa.float64(), "COG": pa.float64(), "Heading": pa.float64(),
        "VesselName": pa.string(), "IMO": pa.string(), "CallSign": pa.string(),
        "VesselType": pa.float64(), "Status": pa.float64(), "Length": pa.float64(), "Width": pa.float64(),
        "Draft": pa.float64(), "Cargo": pa.float64(), "TransceiverClass": pa.string(),
    }
    days = list(pd.date_range(start_date, end_date, freq="D").strftime("%Y-%m-%d"))

    # 1. Source: one batch per day, read from that day's zipped CSV (about 10 million rows)
    def one_batch_per_day():
        for day in days:
            y, m, d = day.split("-")
            zip_path = f"{fused.api.resolve(raw)}AIS_{y}_{m}_{d}.zip"
            with fsspec.open(zip_path, "rb") as f, zipfile.ZipFile(f) as z, z.open(z.namelist()[0]) as csv:
                table = pacsv.read_csv(csv, convert_options=pacsv.ConvertOptions(column_types=types))
            table = table.filter(pc.and_(pc.is_valid(table["LAT"]), pc.is_valid(table["LON"])))
            date = pa.array(np.full(table.num_rows, np.datetime64(day, "D")), pa.date32())
            yield table.append_column("date", date).combine_chunks().to_batches()[0]

    # 2. Partition: one folder per day, one file per res-1 cell, each report as a res-10 hex
    fused.h3.partition(
        one_batch_per_day(),
        out,
        point_column=("LAT", "LON"),
        h3_res=10,
        file_res=1,
        partition_by="date",
        overwrite=True,
    )
    return pd.DataFrame({"days": [len(days)]})
```

The canvas's first step copies the LAZ tiles to `raw` as they are. The partition step reads one tile at a time with [PDAL](https://pdal.io/), which also reprojects it to lat/lng:

```python showLineNumbers {44-53}
@fused.udf(engine="r5.2xlarge")
def udf(
    raw: str = "fd://h3/lidar_laz/",
    out: str = "fd://h3/lidar_manhattan/",
):
    import json

    import fsspec
    import geopandas as gpd
    import pandas as pd
    import pdal
    import pyarrow as pa
    import shapely

    fs = fsspec.filesystem("s3")
    tiles = sorted(fs.glob(f"{fused.api.resolve(raw)}*.laz"))
    nyc = gpd.read_file("https://data.cityofnewyork.us/resource/gthc-hcne.geojson")
    shape = nyc[nyc["boroname"] == "Manhattan"].union_all()
    shapely.prepare(shape)

    # 1. Source: one batch per LAZ tile, moved to lat/lng and cut to Manhattan
    def one_batch_per_tile():
        for path in tiles:
            fs.get(path, "/tmp/tile.laz")
            pipeline = pdal.Pipeline(json.dumps([
                {"type": "readers.las", "filename": "/tmp/tile.laz"},
                {"type": "filters.reprojection", "out_srs": "EPSG:4326"},
            ]))
            pipeline.execute()
            a = pipeline.arrays[0]
            a = a[shapely.contains_xy(shape, a["X"], a["Y"])]
            if len(a):
                yield pa.record_batch({
                    "lat": a["Y"], "lon": a["X"], "Z": a["Z"].astype("float32"),
                    "Classification": a["Classification"], "Intensity": a["Intensity"],
                    "ReturnNumber": a["ReturnNumber"], "NumberOfReturns": a["NumberOfReturns"],
                    "time": pd.to_datetime(a["GpsTime"] + 1e9 - 16, unit="s", origin="1980-01-06"),
                    "PointSourceId": a["PointSourceId"],
                })

    # 2. Partition: one file per res-7 cell, each point tagged with its res-12 cell.
    # All of Manhattan (about 18 GB) fits under memory_budget, so nothing spills;
    # each writer holds a whole file (up to 460 MB) in memory, so keep workers low.
    fused.h3.partition(
        one_batch_per_tile(),
        out,
        point_column=("lat", "lon"),
        h3_res=12,
        file_res=7,
        memory_budget=32 << 30,
        workers=2,
        overwrite=True,
    )
    return pd.DataFrame({"tiles": [len(tiles)]})
```

Index it, then query a box. For an exact edge, pad the box by about one cell and cut the rows to it:

```python showLineNumbers
@fused.udf
def udf(out: str = "fd://h3/lidar_manhattan/"):
    fused.h3.index(out, overwrite=True, wait=False)
```

```python showLineNumbers
@fused.udf
def udf(out: str = "fd://h3/lidar_manhattan/"):
    # Every point in a box around the Empire State Building, about 250 m x 210 m
    w, s, e, n = (-73.9872, 40.7475, -73.9842, 40.7494)
    pad = 0.0002  # about one res-12 cell, so edge points whose cell centre is outside are kept
    df = fused.h3.query(out, bbox=(w - pad, s - pad, e + pad, n + pad),
                        columns=["lat", "lon", "Z", "Classification", "Intensity"])
    return df[df["lon"].between(w, e) & df["lat"].between(s, n)]
```

## Tips for large datasets

**Partition**
- Use a batch job (`engine="m5.xlarge"` or larger) for large datasets.
- Pass one batch per source file; rows can be unsorted.
- Use latitude/longitude coordinates (EPSG:4326); `partition()` does not reproject them.
- Reduce `workers` to 2–4 if you run out of memory.
- Convert oversized datasets in parallel with [`.map()`](/guide/working-with-udfs/fused-submit), then partition using `fused.h3.sources.parquet()`.

**Index**
- Pass `wait=False` to `index()` and monitor progress with `fused.h3.index_status()`.
- Rebuild the index whenever you change dataset files.

**Query**
- Queries return at most 2,000,000 rows; split larger requests into smaller queries.
- Filter by location, time, or `partition_by`; apply other filters afterward.
- For exact boundaries, pad the box by one cell, then filter by latitude/longitude.
- Use `format="index"` to preview which row groups a query would read.
