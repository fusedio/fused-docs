# H3 Analytics Overview

[Try the basics of H3 in Fused on Canvas →](https://www.fused.io/canvas/fc_public/Basics_of_H3_in_Fused)

New to H3 in Fused? Start with [Working with H3](/guide/working-with-udfs/udf-best-practices/working-with-h3) for the five-step workflow, then come back here for the details.

## Get your data into H3

Size decides how. Small data (under about 100 MB) is converted inside a UDF every time it runs. Large data is ingested once, so later reads touch only the part you need.

| | Small: convert on the fly | Large: partition, index & query | Large: raster ingestion pipeline |
|---|---|---|---|
| How | Convert inside the UDF on every run | You run each step: partition, index, query | One managed call ingests, aggregates and builds overviews |
| Data | Points, polygons and vectors, single-band rasters | Any: points, vectors, rasters, tables, gridded and multi-dimensional | Single-band rasters |
| API | [`h3_latlng_to_cell()`](/guide/h3-analytics/converting#points) in DuckDB, [`common.gdf_to_hex()`](/guide/h3-analytics/converting#polygons-and-vectors) | [`partition()`](/python-sdk/api-reference/h3#partition), [`index()`](/python-sdk/api-reference/h3#index), [`query()`](/python-sdk/api-reference/h3#query) | [`run_ingest_raster_to_h3()`](/python-sdk/api-reference/h3#run_ingest_raster_to_h3) |
| Guide | [Convert on the fly](/guide/h3-analytics/converting) | [Ingest: partition, index & query](/guide/h3-analytics/hex-datasets) | [Raster ingestion](/guide/h3-analytics/raster-ingestion) |

For rasters where you want aggregation and overviews built in, use the raster ingestion pipeline. For everything else, use partition, index & query.

:::info Working with a very large dataset?
If your dataset doesn't fit the patterns above (hundreds of GB, tens of thousands of files, or a custom ingestion shape), reach out to **info@fused.io**. We can help you scale the ingestion.
:::

## Work with H3 data

Once your data is in H3:

1. **Pick a resolution.** The resolution controls hex size and drives everything downstream: fidelity, storage, and the granularity available for aggregation and joins. See the [Resolution Guide](/guide/h3-analytics/resolution-guide).
2. **Aggregate.** Roll data up to coarser (parent) resolutions to render and analyze it at different zoom levels: sum, mean, max, min or stddev for numerical data; counts or mode for categorical data. See [Aggregations](/guide/h3-analytics/aggregations).
3. **Join.** Two H3 datasets at the same resolution join on `hex` with plain SQL, with no spatial join, even across projections, sparse data, or raster and vector sources. See [Joining](/guide/h3-analytics/joining).
4. **Visualize.** Render hexagons in the Workbench Map Viewer or combine UDFs in Canvas. See [Visualization](/guide/h3-analytics/visualization).
