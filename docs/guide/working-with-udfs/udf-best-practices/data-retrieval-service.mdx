# Data Retrieval Service

Partition and index a large dataset once with [`fused.h3`](/python-sdk/api-reference/h3), then query only the part you need in seconds. New to H3? Start with [Working with H3](/guide/working-with-udfs/udf-best-practices/working-with-h3).

- **Ingest once.** Every query after that reads only the cells and time window it asks for, so it stays fast as the data grows.
- **Open Parquet.** Your data is stored as Parquet files that any modern data stack can read.
- **Incremental updates.** Add new data without rewriting what is already indexed.
- **Call it your way.** Python with `fused.h3.query()`, HTTP with `GET /h3/query`, or straight from a web page with no backend to host.

## What data do you have?

Whatever the type, the steps are the same: **partition**, then **index**, then **query**. Only the partition call changes.

| Your data | Partition with | Example |
|---|---|---|
| Points with `lat` and `lon` columns | `point_column=("lat", "lon")` | NYC 311 complaints, AIS ship positions, LiDAR |
| Rows that already have an H3 cell column | `hex_column="hex"` | Raster pixels averaged per hex, such as Copernicus DEM elevation |
| Weather grids | [`fused.h3.sources.era5()`](/python-sdk/api-reference/h3#sourcesera5) | One day of ERA5 around New York |
| Data that arrives over time | Add `partition_by="date"` to any of the above | Daily 311 complaints, daily weather |

## The workflow

| Step | What it does | Call |
|---|---|---|
| **1. Partition** | Writes rows as H3 Parquet files, one file per parent cell | [`fused.h3.partition()`](/python-sdk/api-reference/h3#partition) |
| **2. Index** | Records which cells and times each file covers | [`fused.h3.index()`](/python-sdk/api-reference/h3#index) |
| **3. Query** | Reads back only the rows you ask for | [`fused.h3.query()`](/python-sdk/api-reference/h3#query) |
| **4. Serve** | Same query over HTTP for any language or web page | [`GET /h3/query`](/rest-api/h3) |

A query can select by:

- Area (bounding box) or point
- H3 cell or a range of cells
- Time window
- Partition value, such as one `date`

Partition and index run live in a UDF or as a [batch job](/guide/working-with-udfs/udf-best-practices/scaling-out). Code for every step is in [Ingest, Index & Query H3 Datasets](/guide/h3-analytics/hex-datasets).

## Try it end to end

[H3_End_to_End_Ingestion](https://www.fused.io/canvas/fc_fused/H3_End_to_End_Ingestion) runs partition, index and query for points, a raster and weather data, with a read-me node on scaling each one up. Open it, run each step, then swap in your own data.

## Query it from anywhere

Every filter is a URL parameter, so the call works from `curl`, a script or a browser:

```bash
curl -G "https://www.fused.io/server/v1/h3/query" \
  --data-urlencode "path=s3://fused-asset/data/ais/ais_week_h3_v2/" \
  -d min_lng=-74.10 -d min_lat=40.55 -d max_lng=-73.90 -d max_lat=40.72 \
  -d time_min=2024-07-03T12:00:00 -d time_max=2024-07-03T12:59:59 \
  -o harbor.parquet
```

This returns the 6,214 ship position reports in New York Harbor for one hour as a Parquet file.
