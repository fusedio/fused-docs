Fused publishes its skills as a [plugin marketplace](https://github.com/fusedio/skills) that GitHub Copilot can install directly. A skill is a set of instructions Copilot loads when a task needs it, so once the Fused plugin is installed, Copilot already knows the `canvas.toml` format, how to structure a UDF, which props each widget takes and which `fused` CLI commands to run. You don't have to explain any of it in your prompts.

The same plugin works in [Claude Code](/guide/working-with-udfs/udf-best-practices/ai-coding-tools). This page covers the two places you use GitHub Copilot: the [Copilot CLI](#copilot-cli) and [Copilot in Visual Studio Code](#visual-studio-code). If you install the plugin with the Copilot CLI, VS Code picks it up too.

## What gets installed

Install the `workbench` plugin from `fused-marketplace`. It adds 10 skills covering UDFs, canvases, widgets, integrations, H3 datasets and the `fused` CLI. [AI Coding Tools](/guide/working-with-udfs/udf-best-practices/ai-coding-tools) lists each one.

## Before you start

You need a GitHub Copilot subscription. You don't need to install the Fused CLI first: the skills use it to push and run canvases, and they tell Copilot to install it with [uv](https://docs.astral.sh/uv/getting-started/installation/) when it's missing. Copilot asks before it runs the install, and may ask you to start a new session afterwards.

Once the CLI is installed, log in to your Fused account:

```bash
fused login
```

To install the CLI yourself, or to see every command the skills can call, see the [CLI Reference](/cli/overview#install).

## Copilot CLI

[Install the Copilot CLI](https://docs.github.com/en/copilot/how-tos/copilot-cli/set-up-copilot-cli/install-copilot-cli), then add the Fused marketplace and install the plugin:

```bash
copilot plugin marketplace add fusedio/skills
copilot plugin install workbench@fused-marketplace
```

The install prints `Plugin "workbench" installed successfully. Installed 10 skills.` To confirm Copilot sees them, list your skills:

```bash
copilot skill list
```

The Fused skills appear under **Plugin skills**. Start a new `copilot` session to use them.

To pull the latest skills, or to remove the plugin:

```bash
copilot plugin update workbench@fused-marketplace
copilot plugin uninstall workbench@fused-marketplace
```

## Visual Studio Code

Copilot Chat in VS Code loads skills from [agent plugins](https://code.visualstudio.com/docs/copilot/customization/agent-plugins). Agent plugins are controlled by the `chat.plugins.enabled` setting, which is on by default. If your organization turns it off, see [Troubleshooting](#troubleshooting).

### Already installed with the Copilot CLI

There is nothing else to do. VS Code discovers plugins installed with the Copilot CLI from `~/.copilot/installed-plugins/`, so `workbench` appears in the **Agent Plugins - Installed** view of the Extensions sidebar.

### Install from VS Code

1. Run **Chat: Manage Plugin Marketplaces** from the Command Palette, select **Add Marketplace...** and enter `fusedio/skills`. VS Code adds it to the `chat.plugins.marketplaces` setting and keeps the marketplaces already there.
2. Open the Extensions view (`⇧⌘X` on macOS, `Ctrl+Shift+X` on Windows and Linux) and search for `@agentPlugins`.
3. Find **workbench** from `fused-marketplace` and select **Install**. The first time you install from a new marketplace, VS Code asks you to trust it.

To check the skills loaded, run **Chat: Open Customizations** from the Command Palette and select **Skills**, or type `/` in the Chat input to list them.

To update, run **Extensions: Check for Extension Updates**. VS Code also checks every 24 hours when `extensions.autoUpdate` is on. To remove the plugin, right-click it in **Agent Plugins - Installed** and select **Uninstall**.

## Try it out

Open a new Copilot session, in the terminal or in VS Code Chat, and ask for a canvas:

```text
Make a Hello World canvas with some dummy data and a chart showing the number of rows in the data
```

Copilot picks the Fused skills the task needs, writes the UDF and the chart widget, and uses the `fused` CLI to push the canvas to your account.

To try it with real data, point Copilot at Fused's public ERA5 weather dataset. The `fused-h3` skill tells Copilot where it is, and reading it needs no credentials:

```text
Make a canvas that charts the daily high temperature in Boulder, Colorado for July 2020 from Fused's public ERA5 dataset, in °F
```

To change a canvas you already have, pull it to a local folder, ask Copilot to edit the files, then push it back. The steps are the same as with Claude Code: see [Editing canvases locally](/guide/working-with-udfs/udf-best-practices/ai-coding-tools#editing-canvases-locally-with-claude).

## Troubleshooting

<details>
<summary>Advanced: install the skills without the plugin</summary>

If your organization has turned off agent plugins, install the skills on their own. They're plain [Agent Skills](https://agentskills.io) folders, and both the Copilot CLI and VS Code read personal skills from `~/.agents/skills`:

```bash
git clone https://github.com/fusedio/skills ~/.fused-plugins
mkdir -p ~/.agents/skills
ln -s ~/.fused-plugins/workbench/skills/* ~/.agents/skills/
```

`copilot skill list` now shows the Fused skills under **Personal skills**. To update them, run `git -C ~/.fused-plugins pull`.

</details>
