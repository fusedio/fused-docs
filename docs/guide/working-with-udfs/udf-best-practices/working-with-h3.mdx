# Working with H3

[H3](https://h3geo.org/) is a hexagonal global grid system. It's a good fit when you need to:
- Build heatmaps of events (populations, counts, etc.)
- Compare datasets across resolutions and scale
- Work with sparse datasets, like point or location data

You can try all of the basics of H3 on this [Canvas →](https://www.fused.io/canvas/fc_public/Basics_of_H3_in_Fused)

A typical H3 workflow has five steps: **get your data into H3**, **pick a resolution**, **aggregate**, **join** with other H3 datasets, and **visualize**. This page is the map; each step links to the page in [H3 Analytics](/guide/h3-analytics/h3-overview) that covers it.

## 1. Get your data into H3

| Your data | Go to |
|-----------|-------|
| Small (under about 100 MB): points, polygons or raster tiles | [Convert on the fly](/guide/h3-analytics/converting): hexagonify inside a UDF on every run |
| Large: points, vectors, tables, or multi-dimensional data such as weather | [Ingest: Partition, Index & Query](/guide/h3-analytics/hex-datasets): write it once, then read back only the part you need |
| Large rasters where you want aggregation and overviews built in | [Ingest: Raster Pipeline](/guide/h3-analytics/raster-ingestion): pixels to hexes, aggregated, with zoomed-out overviews |

Not sure which one fits? [Choose your path](/guide/h3-analytics/h3-overview#choose-your-path) compares them by data type and size.

:::info Working with a very large dataset?
If your dataset doesn't fit the patterns above (hundreds of GB, tens of thousands of files, or a custom ingestion shape), reach out to **info@fused.io**. We can help you scale the ingestion.
:::

## 2. Pick a resolution

The resolution (`res`) controls hex size, and it drives everything downstream: conversion fidelity, how much data you store, and the granularity available for aggregation and joins.

| Resolution | Avg edge length | Typical use case |
|------------|-----------------|-------------------|
| 3 | 59.81 km | Regional |
| 7 | 1.22 km | Neighborhood |
| 9 | 174.38 m | Block |
| 12 | 10.8 m | Building |

See the [Resolution Guide](/guide/h3-analytics/resolution-guide) for the full table and how Fused infers resolution from raster pixel size.

## 3. Aggregate

Once data is in H3, roll it up to coarser (parent) resolutions to make it fast to render and analyze at different zoom levels. Two datasets also need to share a resolution before they can be joined.
- **Numerical** (temperature, elevation, population): sum, mean, max, min, or stddev per cell.
- **Categorical** (land use, crop type): count occurrences, or take the mode, per cell.

See [Aggregations](/guide/h3-analytics/aggregations).

## 4. Join datasets

Two H3 datasets with the same `hex` column and resolution merge with a standard SQL join on `hex`, with no spatial join. This makes it easy to combine datasets in different projections, sparse location data, or raster and vector sources.

See [Joining](/guide/h3-analytics/joining).

## 5. Visualize

Render hexagons in the **Workbench Map Viewer** as an H3 layer, or combine UDFs into an interactive view in **Canvas**.

See [Visualization](/guide/h3-analytics/visualization).
