# Working with Sentinel-2

:::tip Using an AI agent?
Copy [this file](https://docs.fused.io/skills/SENTINEL2.md) and pass it to your AI agent to work with Sentinel-2 data.
:::

[Sentinel-2](https://sentinels.copernicus.eu/copernicus/sentinel-2) is a constellation of Copernicus satellites that image the whole Earth every few days at up to 10 m per pixel. Fused can find scenes, build cloud-free composites, compute indices such as NDVI and follow them through time, for any area and date range.

This page is the map. Each goal below links to the example that covers it and to the canvas you can open and run.

## What do you want to do?

| Goal | Walkthrough | Canvas |
|---|---|---|
| Map an index, follow it through time on H3 hexagons or build a composite, with GeoTIFF, CSV or Parquet download, or the same from one JSON API | [Sentinel-2 Explorer](/examples/sentinel-2-explorer) | [Sentinel2_Explorer](https://www.fused.io/canvas/fc_fused/Sentinel2_Explorer) |

## Where the imagery comes from

Sentinel-2 L2A scenes are public on AWS Open Data and are listed in STAC catalogs. The examples use three ways to find them:

| Catalog | Used by |
|---|---|
| Fused's partitioned Sentinel-2 L2A STAC index, `s3://fused-asset/stac/sentinel-2-l2a/partitioned_2015_2025/` | [Monthly Median Composite](/examples/monthly-median-composite) |
| [`s2-stac-geoparquet`](https://source.coop/tge-labs/s2-stac-geoparquet) on Source Cooperative | [Sentinel-2 Composite](/examples/sentinel-2-composite) |
| [Earth Search](https://earth-search.aws.element84.com/v1) STAC API | [Sentinel2_Toolkit](https://www.fused.io/canvas/fc_fused/Sentinel2_Toolkit) |

- The canvases above are built on `sentinel_utils`, so you work with this data yourself through its [utility functions](#utility-functions).

## Scale out with `.map()`

A long date range is many small jobs. Run one job per month or per few days in parallel with [`.map()`](/python-sdk/api-reference/udf#map). [Monthly Median Composite](/examples/monthly-median-composite) runs one machine per month, and the [Explorer](/examples/sentinel-2-explorer) reads its H3 table with one job per 10 days. [Sentinel-2 Composite](/examples/sentinel-2-composite) splits a large area into blocks that run in parallel. See [Scaling out UDFs](/guide/working-with-udfs/udf-best-practices/scaling-out) for the pattern.

## Utility functions

[Sentinel2_Toolkit](https://www.fused.io/canvas/fc_fused/Sentinel2_Toolkit) is a library of Sentinel-2 helpers, with one node per module and a set of example nodes you can run:

- Search scenes and read their dates and cloud cover.
- Request bands, mosaics and composites, and compute indices (NDVI, NDWI, MNDWI, NDMI, NBR, NDSI, NDRE, EVI, SAVI and BSI).
- Statistics per interval over a polygon, and a Copernicus DEM and AlphaEarth embeddings.
- Examples for classification, change detection, timelapse and export.

The same code is published as [`public/sentinel_utils`](https://github.com/fusedio/udfs/tree/main/public/sentinel_utils) in the Fused UDFs repo, as three modules: `su_search`, `su_read` and `su_analysis`. Open the canvas and read its README for the function list.

## Combine with H3

NDVI on a hexagon grid joins to any other H3 dataset on the `hex` column. [H3_Parcel_Suitability](https://www.fused.io/canvas/fc_fused/H3_Parcel_Suitability) joins NDVI, elevation, irrigation and weather onto parcels. To do the same with your own data, follow [Working with H3](/guide/working-with-udfs/udf-best-practices/working-with-h3). The [Explorer](/examples/sentinel-2-explorer) also builds an H3 table of an index per day, which you can download as CSV or Parquet.
