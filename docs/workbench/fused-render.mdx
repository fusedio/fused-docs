[Fused Render](https://render.fused.io) is a desktop app that opens your Workbench canvases locally, with the live Workbench embedded next to an AI chat. You ask a coding agent to change a canvas, it edits the files on your machine, and every save is pushed back to the hosted Workbench.

![Fused Render home page with Fused Apps and AI Playground](/img/workbench/fused-render/app-home.jpg)

### 1. Install Fused Render

<Tabs className="unique-tabs">
  <TabItem value="mac" label="macOS" default>

Download the `.dmg` from [render.fused.io](https://render.fused.io), open it and drag **Fused Render** into Applications. The macOS app is built for Apple silicon.

  </TabItem>
  <TabItem value="windows" label="Windows">

On Windows, Fused Render installs as a Python package with [uv](https://docs.astral.sh/uv/). In PowerShell, install uv and add it to the `PATH` of the current session:

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
$env:Path = "$env:USERPROFILE\.local\bin;$env:Path"
```

Install and start Fused Render. uv downloads its own Python:

```powershell
uv tool install --force --python 3.12 "fused-render[cli]"
uv tool update-shell
fused-render
```

  </TabItem>
  <TabItem value="wsl" label="Windows (WSL)">

If Fused Render doesn't run natively on Windows, run it inside Ubuntu on WSL. In PowerShell, install Ubuntu:

```powershell
wsl --install -d Ubuntu
```

In Ubuntu, install uv with [mise](https://mise.jdx.dev/), then install Fused Render:

```bash
sudo apt update -y && sudo apt upgrade -y
sudo add-apt-repository -y ppa:jdxcode/mise
sudo apt install -y mise
mise use -g uv@latest
echo 'eval "$(mise activate bash)"' >> ~/.bashrc && eval "$(mise activate bash)"
uv tool install --force "fused-render[cli]"
uv tool update-shell
```

Restart your shell, then run `fused-render`.

To use GitHub Copilot as the agent, install it in Ubuntu, restart your shell, then run `copilot`, type `/login` and send a test message to check it works:

```bash
curl -fsSL https://gh.io/copilot-install | bash
```

If a proxy such as Zscaler stops the sign-in page from opening, point `BROWSER` at Chrome on Windows when you start Fused Render:

```bash
export BROWSER='/mnt/c/Program Files/Google/Chrome/Application/chrome.exe'; fused-render
```

  </TabItem>
  <TabItem value="linux" label="Linux">

Download the AppImage from [render.fused.io](https://render.fused.io), then make it executable and run it. Linux support is in beta, so some features may be missing.

```bash
chmod +x FusedRender-*-x86_64.AppImage
./FusedRender-*-x86_64.AppImage
```

To install it as a Python package instead, use [uv](https://docs.astral.sh/uv/getting-started/installation/):

```bash
uv tool install --force "fused-render[cli]"
fused-render
```

  </TabItem>
</Tabs>

### 2. Sign in to Fused

:::note
You need a Fused account, and an account for each coding agent you use (Claude, GitHub Copilot, ChatGPT or Google).
:::

Open **Preferences > Accounts** and select **Sign in** on **Fused account**. Your browser opens fused.io to finish signing in.

![Accounts page in Fused Render Preferences showing a signed-in Fused account](/img/workbench/fused-render/accounts.png)

### 3. Turn on Canvases

In **Preferences > Experimental flags**, turn on **Canvases** to add it to the sidebar.

![Experimental flags page with the Canvases toggle turned on](/img/workbench/fused-render/canvases_flag.png)

### 4. Open a canvas

Select **Canvases** in the sidebar to see every canvas in your Fused account. Pick the **Environment** at the top, then click a canvas to clone it to your machine and open it. **+ New canvas** creates an empty one.

![Workbench Canvases page listing canvases with their UDF counts](/img/workbench/fused-render/canvases.png)

Ask the agent in the chat for a change, for example *"Add a map widget showing the output of hex_overview"*. When it saves, the top bar shows **Published**.

![A canvas open in Fused Render with the Workbench on the left and the chat panel on the right](/img/workbench/fused-render/canvas.png)

### 5. Choose a coding agent

Fused Render uses Claude Code by default. To use another agent, open **Preferences > Coding agents** and turn on GitHub Copilot CLI, OpenAI Codex CLI or Google Gemini CLI. Chats and tasks then run with that agent. Each agent must be installed and signed in on your machine; the page shows whether it is ready.

![Coding agents page with toggles for Claude Code, GitHub Copilot CLI, OpenAI Codex CLI and Google Gemini CLI](/img/workbench/fused-render/coding_agents.png)

To give these agents the Fused skills outside Fused Render, see [AI Coding Tools](/guide/working-with-udfs/udf-best-practices/ai-coding-tools) and [GitHub Copilot](/guide/working-with-udfs/udf-best-practices/github-copilot).
