Workbench is a browser-based platform to build with data. Write Python, visualize results instantly, and share your work.

## Views

**[Canvas](/workbench/udf-builder/canvas)** — Default view for building workflows. Connect UDFs together, create dashboards, and see results side-by-side.

**[Map Builder](/workbench/udf-builder/)** — Advanced view for geospatial workflows. Visualize multiple UDFs as map layers or inspect individual Table outputs.

## Tools

**[File Explorer](/workbench/file-explorer)** — Browse and open files directly from cloud storage (S3, GCS, Azure).

**[Fused Render](/workbench/fused-render)**: Open your canvases in a desktop app and edit them with a local coding agent.

**[UDF Explorer](/workbench/udf-explorer)** — Organize and share your UDFs. Supports version control through GitHub.
