# H3 data retrieval on Fused

`fused.h3` makes a large geospatial dataset fast to query: **partition** it into H3 Parquet files, **index** it, then **query** any area, point, H3 cell, time window or partition value. Rules for every Fused task (accounts, errors, expected outputs): https://docs.fused.io/skills/SKILL.md

References: https://docs.fused.io/rest-api/h3 (every REST parameter and error), https://docs.fused.io/python-sdk/api-reference/h3 (`fused.h3`), https://docs.fused.io/widget-api/fused-map (the map widget).

## Set up

```bash
pip install -U "fused[vector]" h3
fused login          # opens the browser; check with `fused whoami`
```

`fd://` is the user's own Fused storage. `s3://` and `gs://` work too if the account can reach the bucket.

## Partition, index, query

```python
import fused


@fused.udf
def nyc311_day(date: str = "2024-07-04"):
    import pandas as pd
    from urllib.parse import urlencode

    query = urlencode({
        "$select": "unique_key, created_date, complaint_type, borough, latitude, longitude",
        "$where": f"created_date between '{date}T00:00:00' and '{date}T23:59:59' AND latitude IS NOT NULL",
        "$limit": 100000,
    })
    df = pd.read_csv(f"https://data.cityofnewyork.us/resource/erm2-nwe9.csv?{query}")
    df["date"] = date
    return df


path = "fd://h3_examples/nyc311_one_day/"
run = fused.h3.partition(
    fused.h3.sources.udf(nyc311_day),
    path,
    point_column=("latitude", "longitude"),
    h3_res=11,
    partition_by="date",
)
run.tail()

fused.h3.index(path).tail()


@fused.udf
def nyc311_area(path: str, date: str = "2024-07-04"):
    import fused

    return fused.h3.query(path, bbox=(-74.02, 40.70, -73.93, 40.80), partition={"date": date})


df = fused.run(nyc311_area, path=path)
```

- `nyc311_day()` returns 10,492 rows with columns `unique_key`, `created_date`, `complaint_type`, `borough`, `latitude`, `longitude`, `date`.
- `partition` takes a source such as `fused.h3.sources.udf(...)`, not a DataFrame (`TypeError`). It returns a run at once and prints `fused.h3.partition: started run grp:... (1 job) into s3://...`. The work runs on Fused batch jobs: `run.tail()` streams the logs for about 2 minutes, `run.wait()` waits silently, then `run.status()` is `'succeeded'`.
- `index` takes a few seconds. Index again after every partition: a query that reaches a file changed after indexing fails with HTTP 409.
- `fused.h3.query` runs only inside a UDF on Fused, so wrap it as above; anywhere else it raises `RuntimeError`. It returns a DataFrame, here 1,312 rows: the source columns plus `hex` (uint64 H3 cell). Always give a place: with none, the whole dataset comes back.

## In the browser: `h3-query` widget

A JSON-UI `h3-query` widget runs one `GET /h3/query` and publishes the rows as `{{name}}`; a `fused-map` layer draws them with `"data": "{{name}}"`, and no UDF runs. Spec and example: https://docs.fused.io/skills/h3/h3-query-widget.md
