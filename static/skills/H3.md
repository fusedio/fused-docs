# H3 Data Retrieval on Fused

Use `fused.h3` to make a large geospatial dataset fast to query: **partition** it into H3 Parquet files, **index** it, then **query** any area, point, H3 cell, time window or partition value, from Python or over HTTP with `GET /h3/query`. Every call runs on the user's own Fused account. Never call a canvas share link from code: it runs as the canvas owner.

Each snippet says what to expect. Numbers come from live data, so they can differ a little. Check the shape and columns first.

References: https://docs.fused.io/rest-api/h3 (every REST parameter and error), https://docs.fused.io/python-sdk/api-reference/h3 (`fused.h3`), https://docs.fused.io/widget-api/fused-map (the map widget).

## Set up

```bash
pip install -U "fused[vector]" h3
fused login          # opens the browser; check with `fused whoami`
```

`fd://` is the user's own Fused storage. `s3://` and `gs://` work too if the account can reach the bucket.

## 1. Partition

`partition` takes a **source**, not a DataFrame: passing a DataFrame raises `TypeError`. A source is one of:

- `fused.h3.sources.udf(my_udf)`: a UDF that returns the rows. Use this for data you have in Python.
- `fused.h3.sources.era5(outputs=[...], date=..., bbox=...)`: ERA5 weather, with `fill="nearest"`.
- A folder path on `fd://`, `s3://` or `gs://`, or `fused.h3.sources.parquet(path)`: Parquet already in storage.

The work runs on Fused batch jobs. `partition` returns a run at once; `.wait()` blocks until it finishes.

```python
import fused


@fused.udf
def nyc311_day(date: str = "2024-07-04"):
    import pandas as pd
    from urllib.parse import urlencode

    query = urlencode({
        "$select": "unique_key, created_date, complaint_type, borough, latitude, longitude",
        "$where": f"created_date between '{date}T00:00:00' and '{date}T23:59:59' AND latitude IS NOT NULL",
        "$limit": 100000,
    })
    df = pd.read_csv(f"https://data.cityofnewyork.us/resource/erm2-nwe9.csv?{query}")
    df["date"] = date
    return df


path = "fd://h3_examples/nyc311_one_day/"
run = fused.h3.partition(
    fused.h3.sources.udf(nyc311_day),
    path,
    point_column=("latitude", "longitude"),
    h3_res=11,
    partition_by="date",
    overwrite=True,
)
run.wait()
```

Expect `nyc311_day()` to return 10,492 rows with columns `unique_key`, `created_date`, `complaint_type`, `borough`, `latitude`, `longitude`, `date`. `partition` prints `started run grp:...`; `run.wait()` takes about 2 minutes, then `run.status()` is `'succeeded'`.

How rows get a cell:

- Points: `point_column=("lat", "lon")`, in EPSG:4326. `h3_res` is the cell resolution.
- Rows with an H3 cell column (uint64): `hex_column="hex"`.

`partition_by` is for nonspatial columns such as `date` or `scenario`, never location. `file_res` sets how much area one file covers.

### Many days: `parts`

Give the source UDF a parameter and pass one dict per part. Parts run in parallel.

```python
import fused
import pandas as pd

days = pd.date_range("2024-07-04", "2024-07-05").strftime("%Y-%m-%d")
run = fused.h3.partition(
    fused.h3.sources.udf(nyc311_day),
    "fd://h3_examples/nyc311_days/",
    point_column=("latitude", "longitude"),
    h3_res=11,
    partition_by="date",
    parts=[{"date": d} for d in days],
)
run.wait()
```

Expect `started run grp:... (2 parts)`, about 2 minutes. Rules:

- Each part key must be a column the source returns (`date` here). Otherwise the part fails with `returned no 'date' column; partition keys must be output columns`.
- `overwrite=True` is not allowed with `parts`. Pass `force=True` to redo parts, or write to a new path.
- A run started elsewhere (for example inside a UDF that returned `run.id`): `fused.h3.get_run(run_id).status()`.
- Adding data later: partition only the new rows with `append=True`, then index again without `overwrite`.

## 2. Index

```python
fused.h3.index(path, overwrite=True).wait()
status = fused.h3.index_status(path)
```

Expect `index` to take a few seconds. `status` is a dict: `status` `'ready'`, `files` 1, `resolution` 11, `hex_column` `'hex'`, `partition_columns` `[{'name': 'date', 'type': 'string', 'distinct': 1, 'min': '2024-07-04', 'max': '2024-07-04'}]`, plus `time_min`, `time_max`, `row_groups`, `failures`. Query before `.wait()` finishes and you get `This location is still 'indexing'`. For a timestamp column inside the files, pass `time_column="name"`. Index again whenever the files change.

`index_status` also works on a public dataset you did not build. Expect `fused.h3.index_status("s3://fused-asset/data/nyc311/")` to give `files` 1923, `resolution` 11, `partition_columns` `[{'name': 'month', 'type': 'string', 'distinct': 192, 'min': '2010-01', 'max': '2025-12'}]`, `time_min` `'2010-01-01T00:00:00'`.

## 3. Query

```python
df = fused.h3.query(path, bbox=(-74.02, 40.70, -73.93, 40.80), partition={"date": "2024-07-04"})
```

Expect a DataFrame, 1,312 rows: the source columns plus `hex` (uint64 H3 cell). Give at most one spatial selector:

| Selector | Example | Rows here |
|---|---|---|
| `bbox=(min_lng, min_lat, max_lng, max_lat)` | above | 1,312 |
| `cell=` a coarser or equal cell, as a hex string | `cell="872a10088ffffff"` | 67 |
| `lat=`, `lng=` | a point | the rows in that cell |
| `hex_range=(min, max)` | two hex strings | every row between them |

Narrow further with `time_min`/`time_max` (ISO strings), `partition={...}`, `partition_range={"date": ["2024-07-01", "2024-07-07"]}` and `columns=[...]`. Only the named columns come back, so list `"hex"` in `columns` when you need the cell. A query matches whole cells: for an exact edge, pad the box by about one cell and filter by latitude and longitude. A result too large for one read fails with HTTP 413: split the area or time window.

The same call reads a public dataset with no setup:

```python
df = fused.h3.query(
    "s3://fused-asset/data/nyc311/",
    bbox=(-73.990, 40.750, -73.980, 40.758),
    partition={"month": "2025-12"},
)
pt = fused.h3.query(
    "s3://fused-asset/data/nyc311/",
    lat=40.7522, lng=-73.9858,
    partition={"month": "2025-12"},
    columns=["hex", "complaint_type"],
)
```

Expect `df` to have 752 rows and 47 columns (`unique_key`, `created_date`, `complaint_type`, `latitude`, `longitude`, ..., `month`, `hex`), and `pt` 38 rows with columns `hex`, `complaint_type`.

## Query over HTTP

`GET https://www.fused.io/server/v1/h3/query` returns Parquet (`application/vnd.apache.parquet`). A public `s3://` dataset needs no credentials. All parameters: https://docs.fused.io/rest-api/h3. Interactive docs: https://www.fused.io/server/docs.

The examples use two public datasets: NYC 311 at `s3://fused-asset/data/nyc311/` (resolution 11, partitioned by `month`, time column `created_date`, 2010-01 to 2025-12) and AIS ship positions at `s3://fused-asset/data/ais/ais_week_h3_v2/` (resolution 10, time column `BaseDateTime`, July to October 2024).

### Bounding box

```bash
curl -G "https://www.fused.io/server/v1/h3/query" \
  --data-urlencode "path=s3://fused-asset/data/nyc311/" \
  -d min_lng=-73.990 -d min_lat=40.750 -d max_lng=-73.980 -d max_lat=40.758 \
  --data-urlencode 'partition={"month": "2025-12"}' \
  -o nyc311.parquet
```

Expect HTTP 200, about 88 KB, 752 rows, 47 columns including `hex` (uint64), `created_date`, `complaint_type`, `latitude`, `longitude`, `month`.

### Point

```bash
curl -G "https://www.fused.io/server/v1/h3/query" \
  --data-urlencode "path=s3://fused-asset/data/nyc311/" \
  -d lat=40.7522 -d lng=-73.9858 \
  --data-urlencode 'partition={"month": "2025-12"}' \
  -o point.parquet
```

Expect HTTP 200 and 38 rows: every row in the resolution 11 cell that contains the point. A point in an empty cell gives HTTP 200 and 0 rows.

### Cell

```bash
curl -G "https://www.fused.io/server/v1/h3/query" \
  --data-urlencode "path=s3://fused-asset/data/nyc311/" \
  -d cell=892a100d2d3ffff \
  --data-urlencode 'partition={"month": "2025-12"}' \
  -o cell.parquet
```

Expect HTTP 200 and 100 rows: a resolution 9 cell returns every row in its resolution 11 children. Get a cell id with `h3.latlng_to_cell(40.7522, -73.9858, 9)`.

### Cell range

```bash
curl -G "https://www.fused.io/server/v1/h3/query" \
  --data-urlencode "path=s3://fused-asset/data/nyc311/" \
  -d hex_min=8b2a100d2d00fff -d hex_max=8b2a100d2d3ffff \
  --data-urlencode 'partition={"month": "2025-12"}' \
  -o range.parquet
```

Expect HTTP 200 and 100 rows, the same as the cell above: the range is inclusive and covers the cell's children. Use it for a run of cells from a sorted list.

### Partition and partition range

```bash
curl -G "https://www.fused.io/server/v1/h3/query" \
  --data-urlencode "path=s3://fused-asset/data/nyc311/" \
  -d min_lng=-73.990 -d min_lat=40.750 -d max_lng=-73.980 -d max_lat=40.758 \
  --data-urlencode 'partition_range={"month": ["2025-10", "2025-12"]}' \
  -o quarter.parquet
```

Expect HTTP 200 and 2,488 rows with `month` in `2025-10`, `2025-11`, `2025-12`. `partition={"month": ["2025-11", "2025-12"]}` (a list) gives 1,592 rows. Without `partition` the query reads every month, so always set one on a dataset this large.

### Columns

```bash
curl -G "https://www.fused.io/server/v1/h3/query" \
  --data-urlencode "path=s3://fused-asset/data/nyc311/" \
  -d min_lng=-73.990 -d min_lat=40.750 -d max_lng=-73.980 -d max_lat=40.758 \
  --data-urlencode 'partition={"month": "2025-12"}' \
  -d columns=created_date -d columns=complaint_type -d columns=latitude -d columns=longitude \
  -o columns.parquet
```

Expect HTTP 200, 15 KB instead of 88 KB, 752 rows and exactly those 4 columns. `hex` is not included unless you ask for it: add `-d columns=hex`.

### Time window

```bash
curl -G "https://www.fused.io/server/v1/h3/query" \
  --data-urlencode "path=s3://fused-asset/data/ais/ais_week_h3_v2/" \
  -d min_lng=-74.10 -d min_lat=40.55 -d max_lng=-73.90 -d max_lat=40.72 \
  -d time_min=2024-07-03T12:00:00 -d time_max=2024-07-03T12:59:59 \
  -d columns=MMSI -d columns=VesselName -d columns=BaseDateTime \
  -d columns=LAT -d columns=LON -d columns=SOG \
  -o harbor.parquet
```

Expect HTTP 200, about 104 KB and 6,214 rows: one hour of ship positions in New York Harbor. On NYC 311, `time_min=2025-12-24T00:00:00 -d time_max=2025-12-26T23:59:59` with the bounding box above gives 59 rows, with or without `partition`.

### Paging

A large result comes back one page at a time. When more remain, the response has an `X-Fused-Next-Cursor` header. Send it back as `cursor=` with the same query until a response has none. `max_row_groups=1` forces paging so you can test the loop:

```bash
curl -sS -G "https://www.fused.io/server/v1/h3/query" \
  --data-urlencode "path=s3://fused-asset/data/ais/ais_week_h3_v2/" \
  -d min_lng=-74.10 -d min_lat=40.55 -d max_lng=-73.90 -d max_lat=40.72 \
  -d time_min=2024-07-03T12:00:00 -d time_max=2024-07-03T12:59:59 \
  -d max_row_groups=1 -D page1.headers -o page1.parquet
CURSOR=$(grep -i x-fused-next-cursor page1.headers | cut -d' ' -f2 | tr -d '\r')
curl -sS -G "https://www.fused.io/server/v1/h3/query" \
  --data-urlencode "path=s3://fused-asset/data/ais/ais_week_h3_v2/" \
  -d min_lng=-74.10 -d min_lat=40.55 -d max_lng=-73.90 -d max_lat=40.72 \
  -d time_min=2024-07-03T12:00:00 -d time_max=2024-07-03T12:59:59 \
  -d max_row_groups=1 --data-urlencode "cursor=$CURSOR" -D page2.headers -o page2.parquet
```

Expect page 1 to have 86 rows and a 274 character cursor, page 2 to have 1 row and a new cursor. A cursor from a different query or from before a re-index fails with HTTP 400 or 409.

### Stats and files

`format=stats` returns per row group minimum and maximum of the columns you name, without reading rows:

```bash
curl -G "https://www.fused.io/server/v1/h3/query" \
  --data-urlencode "path=s3://fused-asset/data/nyc311/" \
  -d min_lng=-73.990 -d min_lat=40.750 -d max_lng=-73.980 -d max_lat=40.758 \
  --data-urlencode 'partition={"month": "2025-12"}' \
  -d format=stats -d columns=created_date -d columns=agency
```

Expect JSON: `h3_resolution` 11, `partitions` `["s3://fused-asset/data/nyc311/month=2025-12"]`, `next_cursor` null and `row_groups` with 2 entries, each with `h3_min`, `h3_max` (hex strings), `partition` (an index into `partitions`) and `stats` such as `created_date` min `2025-12-01T00:00:42`, max `2025-12-31T23:58:25`. When `next_cursor` is set, send it as `cursor=`.

`format=files` lists the indexed files the query would open:

```bash
curl -G "https://www.fused.io/server/v1/h3/query" \
  --data-urlencode "path=s3://fused-asset/data/nyc311/" \
  -d min_lng=-73.990 -d min_lat=40.750 -d max_lng=-73.980 -d max_lat=40.758 \
  --data-urlencode 'partition={"month": "2025-12"}' \
  -d format=files
```

Expect `{"h3_resolution":11,"files":["852a100ffffffff","852a1073fffffff"],"row_counts":{...}}`: two resolution 5 files, 110,015 and 15,547 rows. Use it to size a query before reading it. `format=files` is never paged.

### The user's own dataset

Add a bearer token from `fused.api.access_token()`:

```bash
curl -G "https://www.fused.io/server/v1/h3/query" \
  -H "Authorization: Bearer $FUSED_ACCESS_TOKEN" \
  --data-urlencode "path=fd://h3_examples/nyc311_one_day/" \
  -d min_lng=-74.02 -d min_lat=40.70 -d max_lng=-73.93 -d max_lat=40.80 \
  --data-urlencode 'partition={"date": "2024-07-04"}' \
  -o nyc311.parquet
```

Expect HTTP 200 and 1,312 rows.

### Errors

The body is JSON with a `detail` message. Read it, change the request, then retry.

| Status | Example `detail` | Fix |
|---|---|---|
| 400 | `Pass both lat and lng` | Give both, or use another selector |
| 400 | `Pass at most one of cell, lat/lng, a bounding box, or hex_min/hex_max` | Drop all but one spatial selector |
| 400 | `partition: 'day' is not a partition column of this location (has ['month'])` | Use the column from `format=files` or `index_status` |
| 403 | `Sign in to read this path. Without signing in, only publicly readable s3:// locations can be queried.` | Add the bearer token; an `fd://` path or an unknown `s3://` path gives this too |
| 409 | the dataset has never finished indexing, or the cursor predates a re-index | Wait for `index`, or restart paging without the cursor |
| 422 | `Columns missing from the indexed files: nope` | Check column names against a small query |

### From Python with `requests` and pandas

```python
import io
import pandas as pd
import requests

URL = "https://www.fused.io/server/v1/h3/query"
params = {
    "path": "s3://fused-asset/data/nyc311/",
    "min_lng": -73.990, "min_lat": 40.750, "max_lng": -73.980, "max_lat": 40.758,
    "partition": '{"month": "2025-12"}',
    "columns": ["hex", "created_date", "complaint_type", "latitude", "longitude"],
}
pages, cursor = [], None
while True:
    r = requests.get(URL, params={**params, **({"cursor": cursor} if cursor else {})})
    r.raise_for_status()
    pages.append(pd.read_parquet(io.BytesIO(r.content)))
    cursor = r.headers.get("X-Fused-Next-Cursor")
    if not cursor:
        break
df = pd.concat(pages, ignore_index=True)
```

Expect 1 page and 752 rows with the 5 columns, `hex` as uint64. `df["complaint_type"].value_counts()` starts with `Illegal Parking` 115, `Vendor Enforcement` 77. A list in `params` repeats the parameter, which is what `columns` needs. For a private path add `headers={"Authorization": f"Bearer {fused.api.access_token()}"}`.

### From a browser with `fetch`

The endpoint allows cross-origin requests, so a page can read a public dataset directly. Parse the Parquet with hyparquet:

```js
import { parquetReadObjects } from "https://cdn.jsdelivr.net/npm/hyparquet@1.31.2/+esm";

const q = new URLSearchParams({
  path: "s3://fused-asset/data/nyc311/",
  min_lng: -73.990, min_lat: 40.750, max_lng: -73.980, max_lat: 40.758,
  partition: JSON.stringify({ month: "2025-12" }),
});
["hex", "created_date", "complaint_type", "latitude", "longitude"].forEach(c => q.append("columns", c));
const r = await fetch("https://www.fused.io/server/v1/h3/query?" + q);
if (!r.ok) throw new Error("HTTP " + r.status + ": " + await r.text());
const rows = await parquetReadObjects({ file: await r.arrayBuffer() });
const next = r.headers.get("X-Fused-Next-Cursor");
```

Expect `rows.length` 752, `next` null, and `rows[0]` like `{hex: 626740323063173119n, created_date: 2025-12-06T16:58:00.000Z, complaint_type: 'Noise - Vehicle', latitude: 40.7498, longitude: -73.9814}`. `hex` is a BigInt; keep it as one or convert with `.toString(16)`. A map that queries one tile per request this way, with a month picker and paging, is in https://docs.fused.io/guide/h3-analytics/hex-datasets.

## Visualize with the `fused-map` widget

In a Workbench canvas, a `fused-map` widget draws H3 cells as hexagons. Full props: https://docs.fused.io/widget-api/fused-map. Guide: https://docs.fused.io/guide/h3-analytics/visualization.

### From a UDF: `h3` layer

A UDF queries the dataset and returns one row per cell; the widget draws the result. Save the UDF as `nyc311_hexes`, the widget as a JSON-UI node, and add the edge `["nyc311_hexes", "hex_map"]` in `canvas.toml`.

```python
import fused


@fused.udf
def udf(month: str = "2025-12"):
    df = fused.h3.query(
        "s3://fused-asset/data/nyc311/",
        bbox=(-73.990, 40.750, -73.980, 40.758),
        partition={"month": month},
        columns=["hex", "complaint_type"],
    )
    return df.groupby("hex", as_index=False).size().rename(columns={"size": "count"})
```

```json
{
  "type": "fused-map",
  "props": {
    "layers": [
      {
        "id": "nyc311_hexes",
        "name": "NYC 311, December 2025",
        "udf": "{{nyc311_hexes}}",
        "type": "h3",
        "h3Column": "hex",
        "tooltip": true,
        "legend": true,
        "style": {
          "fillColor": {"type": "continuous", "attr": "count", "palette": "OrYel", "domain": [0, 40]},
          "opacity": 0.8
        }
      }
    ]
  }
}
```

Expect the UDF to return 167 rows with columns `hex`, `count` (`fused run "" nyc311_hexes.py --engine local` prints them), and the map to fly to Midtown with 167 hexagons coloured by `count` and a legend from 0 to 40. `{{nyc311_hexes?month=$month}}` lets a `dropdown` with `"param": "month"` in the same widget change the month.

### Straight from `/h3/query`: `fused-hex` layer

No UDF: the widget sends one `/h3/query` request per map tile. `type` must be set, it is never detected.

```json
{
  "type": "fused-map",
  "props": {
    "basemap": "mapbox://styles/mapbox/dark-v11",
    "centerLng": -73.985,
    "centerLat": 40.754,
    "zoom": 14,
    "layers": [
      {
        "id": "nyc311_rest",
        "name": "NYC 311, December 2025",
        "type": "fused-hex",
        "h3Column": "hex",
        "source": {
          "path": "s3://fused-asset/data/nyc311/",
          "timeColumn": "created_date",
          "dateMin": "2025-12-01",
          "dateMax": "2025-12-31T23:59:59",
          "variables": ["year"],
          "reduce": "sum"
        },
        "tooltip": ["hex", "count"],
        "legend": {"title": "311 requests"},
        "style": {
          "fillColor": {"type": "continuous", "attr": "count", "palette": "Sunset", "domain": [0, 40]},
          "opacity": 0.8
        }
      }
    ]
  }
}
```

Expect hexagons over all of Midtown at zoom 14, coloured by `count`. `reduce: "sum"` collapses each cell's rows in the window to one row and adds `count`, `date_min` and `date_max`; `variables` names the columns to fetch, so keep it to one small column. `source.path` sets the endpoint to `/h3/query`; add `"endpoint": "https://www.fused.io/server/v1/h3/query"` to call another server.

Check a widget before pushing: `fused json-ui validate widget.json` prints `{"valid": true, "errors": []}`. Then `fused canvas push ./my_canvas` and open the widget in Workbench.

## In a Workbench canvas

Split the steps into UDFs: a source UDF, a partition UDF that calls `fused.h3.sources.udf(fused.load("source_udf_name"))` and returns `run.id`, an index UDF, and a query UDF. The full tested code, with the output of each step: https://docs.fused.io/guide/h3-analytics/data-retrieval-end-to-end.

## Scale up

- Large reads: `read_engine="large"`. Running out of memory: lower `workers` to 2 to 4.
- Hundreds of GB or tens of thousands of files: contact info@fused.io.
