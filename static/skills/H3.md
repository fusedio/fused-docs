# H3 Data Retrieval on Fused

Use `fused.h3` to make a large geospatial dataset fast to query: **partition** it into H3 Parquet files, **index** it, then **query** any area, point, H3 cell, time window or partition value. Every call runs on the user's own Fused account. Never call a canvas share link from code: it runs as the canvas owner.

## Set up

```bash
pip install "fused[vector]>=2.9.3" h3
fused login          # opens the browser; check with `fused whoami`
```

Paths: `fd://` is the user's own Fused storage. `s3://` and `gs://` also work for reading and writing if the user's account can reach the bucket.

## 1. Partition

`partition` takes a source, not a DataFrame. To partition data you have in Python, return it from a UDF and pass `fused.h3.sources.udf(that_udf)`. The work runs on a Fused batch job; `.wait()` blocks until it finishes.

```python
import fused


@fused.udf
def nyc311_day(date: str = "2024-07-04"):
    import pandas as pd
    from urllib.parse import urlencode

    query = urlencode({
        "$select": "unique_key, created_date, complaint_type, borough, latitude, longitude",
        "$where": f"created_date between '{date}T00:00:00' and '{date}T23:59:59' AND latitude IS NOT NULL",
        "$limit": 100000,
    })
    df = pd.read_csv(f"https://data.cityofnewyork.us/resource/erm2-nwe9.csv?{query}")
    df["date"] = date
    return df


path = "fd://h3_examples/nyc311_one_day/"
fused.h3.partition(
    fused.h3.sources.udf(nyc311_day),
    path,
    point_column=("latitude", "longitude"),
    h3_res=11,
    partition_by="date",
    overwrite=True,
).wait()
```

Choose how rows get a cell:

- Points: `point_column=("lat", "lon")`, coordinates in EPSG:4326. `h3_res` is the cell resolution.
- Rows that already have an H3 cell column (uint64): `hex_column="hex"`.
- ERA5 weather: `fused.h3.sources.era5(outputs=[...], date=..., bbox=...)` with `fill="nearest"`.
- Parquet already on `fd://`, `s3://` or `gs://`: pass the folder path, or `fused.h3.sources.parquet(path)`.

`partition_by` is for nonspatial columns such as `date`, `hour` or `scenario`. Never use it for location: rows are already grouped by cell, and `file_res` sets how much area one file covers. To add data later, partition only the new rows with `append=True` in place of `overwrite=True`, then index again without `overwrite`.

## 2. Index

```python
fused.h3.index(path, overwrite=True).wait()
fused.h3.index_status(path)  # status 'ready', files, resolution, partition columns, time range
```

A `date` partition column becomes the time column. For a timestamp column inside the files, pass `time_column="name"`. Index again whenever the files change.

## 3. Query

```python
df = fused.h3.query(path, bbox=(-74.02, 40.70, -73.93, 40.80), partition={"date": "2024-07-04"})
```

Give at most one spatial selector: `bbox=(min_lng, min_lat, max_lng, max_lat)`, `lat=` and `lng=`, `cell="8b2a1072b59ffff"` or `hex_range=(min, max)`. Narrow further with `time_min`/`time_max` (ISO strings), `partition={...}`, `partition_range={"date": ["2024-07-01", "2024-07-07"]}` and `columns=[...]`. A query matches whole cells, so for an exact edge pad the box by about one cell and filter by latitude and longitude afterward. A result too large for one read fails with HTTP 413: split the area or time window.

## Query over HTTP

The same query is `GET https://www.fused.io/server/v1/h3/query`, and it returns Parquet. A public `s3://` dataset needs no credentials:

```bash
curl -G "https://www.fused.io/server/v1/h3/query" \
  --data-urlencode "path=s3://fused-asset/data/ais/ais_week_h3_v2/" \
  -d min_lng=-74.10 -d min_lat=40.55 -d max_lng=-73.90 -d max_lat=40.72 \
  -d time_min=2024-07-03T12:00:00 -d time_max=2024-07-03T12:59:59 \
  -o harbor.parquet
```

For the user's own dataset, add a token from `fused.api.access_token()`:

```bash
curl -G "https://www.fused.io/server/v1/h3/query" \
  -H "Authorization: Bearer $FUSED_ACCESS_TOKEN" \
  --data-urlencode "path=fd://h3_examples/nyc311_one_day/" \
  -d min_lng=-74.02 -d min_lat=40.70 -d max_lng=-73.93 -d max_lat=40.80 \
  --data-urlencode 'partition={"date": "2024-07-04"}' \
  -o nyc311.parquet
```

Repeat `columns=` for several columns. A large result is paged: send the `X-Fused-Next-Cursor` response header back as `cursor=` until there is none. Every parameter: https://docs.fused.io/rest-api/h3. Interactive docs: https://www.fused.io/server/docs.

## Scale up

- Many days or months: give the source UDF a parameter and pass `parts=[{"date": "2024-07-01"}, {"date": "2024-07-02"}, ...]`. Each part is a separate read job.
- Large reads: `read_engine="large"`. Running out of memory: lower `workers` to 2 to 4.
- Hundreds of GB or tens of thousands of files: contact info@fused.io.
